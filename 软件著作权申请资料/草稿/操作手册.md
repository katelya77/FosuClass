## 二、说明

佛课小表校园课表服务软件 V1.0 是面向佛山大学学生的微信小程序。它把班级课表、个人课表、教学周、教室占用和校园地点放在同一个学生端入口中，学生可按周或按天查看课程，也可继续查询教师、教室、课程和空教室安排。

首次使用时，学生可以选择已发布的班级课表，导入本人课表，或者先浏览全校课表。选定当前课表后，首页、今日课程和课程提醒都会采用这份课表；实验课、选修课和临时安排可在个性化课程中补充或调整。需要进一步处理校园任务时，可从页面按钮或小佛助手进入空教室、校园地图、教学周历和提醒等功能。

课表事实以软件发布的数据和页面实际查询结果为准。软件会显示数据更新时间或版本状态；网络异常、新数据暂时不可用时，已经缓存的上一份可用课表仍可继续查看。课程时间、地点和教师信息供学习生活安排参考，如与学校或任课教师的临时通知不一致，应以后者为准。

个人课表文件、账号凭据和本机设置只在完成对应操作所需的范围内使用。页面要求授权、导入文件或开启个人课表相关功能时，会先显示用途和操作结果，用户可根据需要决定是否继续。

## 三、功能特点

首页按教学周显示当前课表。顶部给出课表名称、学期、周次、日期范围和数据更新时间，课表网格按星期和节次排列课程卡片。切换周次后，日期和课程同步变化；点按课程可查看教师、教室、上课周次和节次，无法确定时间的课程会单独列出。

全校课表支持班级、教师、教室和课程四类查询。班级查询按学期、学院、年级、专业和行政班逐级选择，其他查询可输入关键词并配合院系或校区条件。查询结果可打开为统一的课表详情，也可保存在最近查看记录中，方便再次进入。

个人课表既可通过本人授权读取，也可从学校导出的 XLS、XLSX 或表格文件导入，还可直接选择班级课表或手动编辑。文件解析后先显示推荐导入、待处理、冲突和课程预览，用户确认选中课程后才会保存。原课程的本机调整、自行添加的实验课或临时安排可随时恢复、停用或删除，不会改动公共课表来源。

今日课程按当前日期和教学周筛选当天安排，教学周历同时给出每周日期范围、假期和调课说明。空教室查询可指定日期、节次、连续空闲时长和教学楼，结果按楼栋分组，并可继续查看教室当天占用和对应课表。

校园地图提供校区切换、地点关键词搜索和地图聚焦。小佛助手接受文字、斜杠命令和快捷任务，可把下一节课、今日安排、教师课表、空教室、校园地点、课表导入及提醒等操作衔接到相应页面；结果会显示实际查询条件和可查看的来源信息。

课程提醒先根据当前个人课表生成预览，再由用户确认并申请微信服务通知授权。已创建的提醒可暂停、恢复、修改提前时间或删除；授权不足时，页面会给出补充授权入口。

软件在加载新数据时保留本机缓存和上一份可用数据。页面会区分加载中、请求超时、无数据、使用缓存和恢复成功等状态，避免网络失败时把旧结果当作最新数据。设置页可查看数据版本、执行安全刷新、清理旧缓存并提交问题反馈。

## 四、系统要求

| 系统要求 | 最低配置 | 推荐配置 |
| --- | --- | --- |
| 移动设备 | 可正常运行微信的 Android 或 iOS 设备 | 具备稳定存储空间和正常触控功能的智能手机 |
| 客户端 | 支持微信小程序基础能力的微信客户端 | 使用当前稳定版微信客户端 |
| 网络 | 首次加载全校课表、地图或助手任务时可连接互联网 | 使用稳定的移动网络或无线网络；已缓存课表可在网络异常时继续查看 |
| 账号与权限 | 浏览公开课表无需提供学校账号；文件导入需允许选择聊天文件 | 创建课程提醒时按微信提示授权服务通知；个人课表上下文按需开启 |

使用前应确保微信能够正常打开小程序。首次获取课表、地图或校园任务结果时需要网络连接；已经成功加载并缓存的课表，在临时断网时仍可查看，待网络恢复后可在设置页执行安全刷新。

## 五、首页周课表

打开小程序后默认进入底部导航“课表”。顶部显示当前课表、学期、教学周、日期范围和数据更新时间；下方的网格以星期为列、节次为行排列课程卡片。尚未绑定课表时，页面不会生成空白课程，而是引导用户选择班级课表或导入个人课表。

查看其他周课程时，可点按周次切换器或在课表区域左右滑动。日期范围和网格内容会随周次一起更新，切换范围不超过当前学期已经维护的总周数。点按课程卡片后会弹出教师、教室、周次和节次等详情；缺少明确上课时间的课程会出现在“未排入课程”区域，不会被强行放入网格。

首页还提供今日课程、作息时间、个性化课程、校园管家、同步课表和更多功能入口。遇到网络异常时，页面优先保留已经加载成功的缓存课表，并显示数据版本或恢复状态。课程安排只作为学习生活参考，如有临时变化，以学校和任课教师通知为准。

## 六、全校课表查询

底部导航“全校”提供班级、教师、教室和课程四个查询标签，首页选择课表、空教室详情及小佛助手结果也可能跳转到这里。页面适合查询其他班级的安排、教师授课时间、教室占用或某门课程的开课情况。

班级查询需要先选定学期，再依次选择学院、年级、专业和行政班级；学院、年级或专业尚未选定时，查看按钮保持不可用。教师、教室和课程查询通过关键词定位目标，并可使用页面提供的院系或校区条件缩小范围。点按查询后，结果列表显示对象名称、来源和课程数量，继续点按即可打开统一课表详情。

最近打开过的课表会保存在本机，用户可再次进入，也可逐项删除或清空记录。关键词为空、没有匹配结果、请求超时、网络失败和当前没有发布数据时，页面分别显示对应提示；重新加载成功前，不会把旧版本结果标成最新结果。

## 七、课表详情与当前课表绑定

从全校查询结果、最近查看记录、分享链接或空教室详情中的“查看教室课表”进入后，详情页会显示课表名称、学期、类型和当前绑定状态。周次切换器、周课表网格和课程总览使用同一份课程数据，用户可逐周查看，也可点按课程卡片核对具体信息。

某一周没有课程时，页面保留课程总览并提示切换其他周；完全没有可用数据时显示空状态，不补写不存在的课程。分享进入的课表如果尚未绑定，顶部会出现提示条。确认名称和学期无误后，点按“设为当前课表”，按钮将变为“已设为当前课表”，首页、今日课程和提醒功能随后采用这份课表及其数据版本。

## 八、今日课程与教学周历

底部导航“今日”按当前日期、教学周和当前课表整理当天课程，首页的今日提醒也可直接跳转。页面显示日期、课程数量、数据来源和按时间排列的课程卡片，点按卡片可查看课程详情；空教室和校园地图入口便于继续安排当天学习地点。

“周历”列出整个学期的教学周编号、日期范围、周类型、标题和备注，当前周会突出显示。滚动离开当前位置后，可点按“回到本周”重新定位。放假、调课或其他特殊周次按已发布校历显示相应说明。

没有绑定课表或当天无课时，今日页会说明当前原因；教学周数据尚未维护时，周历提示稍后刷新，不自行推算或补写日期。

## 九、空教室查询

全校页、今日页、小佛助手快捷操作和校园服务入口都可打开“空教室查询”。学生先选择日期和至少一个有效节次，再按需要设置连续空闲时长、教学楼、常用教室、收藏楼栋或排除未知楼栋，点按“查询空教室”后查看按楼栋分组的结果。

结果顶部汇总本次筛选条件和匹配数量，每个教室可显示空闲说明、下一次占用和收藏状态。点开教室后可以核对当日占用、复制教室名称或进入该教室的课表；收藏变化会立即反映到后续筛选中。没有匹配结果时，页面建议扩大节次范围或切换教学楼。

查询结论只表示当前发布版本在所选时段未记录课程占用，临时借用、考试或活动仍应以现场安排为准。无发布数据、请求超时和网络失败会显示不同状态，用户可按提示重试。

## 十、个人课表同步与导入确认

首页和设置页的“同步课表”、个性化课程中的 XLS 导入，以及小佛助手的“导入课表”都会进入个人课表流程。页面提供本人授权读取、文件导入、选择班级课表和手动编辑四种来源；某种能力未开放时，对应入口不会显示为可用操作。

使用本人授权读取时，需要填写 6 至 20 位数字学号、非空密码并勾选本人授权。密码只用于本次读取，完成后会被清除。使用文件导入时，先选择目标学期，再从微信聊天文件中选择学校导出的 xls、xlsx、html、htm、txt 或 csv 文件，单个文件不得超过 5MB；格式、大小、学期或网络不符合要求时，页面会说明具体原因。

读取或解析过程中会显示当前步骤和进度。解析完成后，课程按照推荐导入、待处理和冲突分类显示，并提供课程预览。用户可以取消不属于自己的课程，为缺少时间的信息补充星期、节次、周次和地点；结束节次不能早于开始节次，周次需要采用页面能够识别的范围表达。至少选中一门课程后才能确认导入，成功后当前课表切换为个人课表，并可立即返回首页查看。

## 十一、个性化课程管理

从首页“个性化”、更多菜单或个人课表导入中的“手动编辑”进入后，页面分别列出原课表课程和自行添加的课程。原课程可按名称搜索，修改过的项目带有“已调整”状态，并提供恢复原信息按钮；自定义课程带有启用开关、编辑和删除入口。

调整原课程时，可修改教师、教室、星期、节次、周次、备注或颜色。添加实验课、选修课和临时安排时，课程名与时间信息是形成课表卡片的基础内容，课程名不能为空，结束节次不能早于开始节次。保存后，课程立即出现在首页和今日课程的适用位置；停用后保留记录但不再显示，恢复或删除后相关页面同步更新。

页面还提供 XLS 导入以及新增课程 JSON 的导入、导出工具。导入的 JSON 必须为课程数组，结构不正确时不会覆盖现有课程。所有个性化调整仅保存在本机并应用于当前课表，不会改写公共课表数据。


【截图预留：个性化课程页面，显示当前绑定课表、原课表课程、课程查找和编辑入口。】

## 十二、校园地图与地点搜索

今日页、设置页、小佛助手快捷操作和课程相关入口可以打开校园地图。页面先按校区和区域展示已发布地图，搜索框用于查找教学楼及常用地点，结果卡片给出名称、分类和区域信息。

选择校区后输入地点名称或关键词，搜索时会自动去除首尾空格。点按匹配结果，地图定位标记移动到对应位置，用户可以预览或复位地图；需要继续核对课程时，可返回课表查询入口。地图图片或预览加载失败时，页面保留当前位置并显示重试按钮，不会展示未发布的地点信息。

## 十三、小佛助手校园任务

首页“校园管家”、全校页和今日页的相关入口，以及全局小佛悬浮按钮可以打开小佛助手。欢迎页提供下一节课、创建提醒、找空教室和导入课表等快捷任务；用户也可在输入框中键入不超过 600 个字符的问题，或使用斜杠命令。

发送前应尽量说明时间、地点、教师、课程或班级。条件足够时，页面依次显示加载、执行、核验和完成状态，结果可采用文字、列表、详情或课表卡片呈现；需要继续打开页面、设置当前课表或创建提醒时，可点按结果卡片中的操作按钮。条件不足时，助手会要求补充，不会把相近对象混为同一结果；任务进行期间可点按停止。

课程、教师、教室、空教室和教学周信息来自软件已经发布的数据及实际查询结果，结果页可展开查看来源或数据版本。个人课表信息默认不参与助手任务，只有用户主动开启相关权限后才使用必要的本机摘要；账号密码、原始个人文件和完整个人课表不会作为普通对话内容发送。服务暂时不可用时，页面保留已经取得的查询结果或给出恢复入口。

## 十四、课程提醒管理

设置页“课程提醒”、小佛助手快捷操作和助手结果中的提醒入口都可打开提醒管理。创建前需先绑定或导入个人课表；没有可用课表时，页面会引导用户先完成课表准备。

选择提醒类型、提前量和适用课程范围后，页面展示下一次提醒预览。确认计划后点按“创建并授权微信通知”，再按照微信提示完成服务通知授权。创建成功的提醒出现在列表中，并标明当前状态和授权情况；授权被拒绝或关闭时，列表保留提醒并提供补充授权入口。

已有提醒可以暂停、恢复或修改提前时间，不再需要时可删除。删除前会再次询问确认，操作完成后列表立即更新，防止误删仍在使用的提醒。


## 十五、班级课表贡献

当某个行政班级尚未收录或课表需要补充时，可从课程数据维护引导进入“贡献班级课表”。表单要求选择学期并填写年级、学院、专业和行政班级，再粘贴课程数组或带有 `courses` 字段的 JSON；不清楚结构时，可先加载示例模板进行比对。

年级、学院、专业、行政班级和课表内容均为必填项，JSON 必须能够解析为课程数组。提交内容不得包含学号、姓名、密码、Cookie 或其他登录凭据。缺少字段或格式错误时，页面指出具体问题；提交期间按钮显示“正在提交”，成功后提示数据已经进入待审核流程。

贡献的数据不会直接成为公共课表。管理员核对班级信息和课程结构后才决定是否采用，用户无需在该页面执行发布操作。


## 十六、设置、反馈与数据恢复

底部导航“设置”集中管理当前课表、显示偏好、小佛入口、课程提醒和数据状态。顶部课表概览可切换或同步课表；教学周、周末显示和小佛悬浮入口的开关保存后，会在相关页面重新读取并显示当前状态。校园地图、问题反馈、联系、隐私、关于和分享也从这里进入。

课表显示异常时，可先打开数据版本详情，核对当前版本和最近网络状态，再执行安全刷新。页面会区分加载中、刷新成功和中文错误提示；清理旧缓存或恢复新用户状态前会说明影响并再次确认，完成后重新加载当前可用数据。清单刷新、索引预热和诊断信息用于进一步定位数据问题，导出的诊断内容会先去除敏感信息。

仍无法解决时，进入问题反馈，选择类型并填写不超过 3000 字的说明。内容为空时不能提交；提交成功后表单关闭并显示结果，失败时保留已填写内容，便于修改后重试。

## 十七、典型使用流程

首次进入小程序时，可先选择一份已发布的班级课表，也可导入个人课表；暂时不绑定课表的用户仍可进入“全校”浏览公开课程安排。绑定完成后，首页顶部会显示当前课表、学期、教学周和数据更新时间，学生可切换周次并点开课程核对教师、教室、节次和上课周次。

需要查找其他安排时，进入“全校”并选择班级、教师、教室或课程查询方式，打开目标课表详情；确认内容适合本人使用后，可将其设为当前课表。当天出发前进入“今日”查看按时间排列的课程，需要自习地点时继续打开空教室或校园地图；学期安排发生变化时，可在教学周历核对当前周、假期和调课说明。

## 十八、常见问题解答

问题：首页为什么没有显示周课表？
解决方法：先在首页引导或全校页选择一个班级课表，也可以从同步课表导入个人课表。完成绑定后返回首页，确认顶部显示了正确的当前课表和学期。

问题：课表与学校临时通知不一致怎么办？
解决方法：先在设置的数据版本详情中执行安全刷新，仍不一致时以学校或任课教师正式通知为准，并通过问题反馈说明课程、日期和差异。

问题：导入 XLS 文件提示格式不支持怎么办？
解决方法：请选择学校导出的xls、xlsx文件，或包含课表表格的html、htm、txt、csv文件；文件不能超过5MB。不要上传截图、压缩包或加密文件。

问题：如何添加实验课或临时调课？
解决方法：从首页进入个性化课程，点按添加课程，填写课程名、星期、节次和周次后保存。原课表已有课程可直接编辑显示信息，并可随时恢复原信息。

问题：空教室结果是否代表一定可以使用？
解决方法：结果只表示当前发布课表版本在所选节次未记录课程占用，临时借用、考试和活动可能未包含，实际使用前应遵守现场管理安排。

问题：小佛助手为什么要求补充条件？
解决方法：教师、课程、班级、日期或节次不明确时，助手会要求补充必要信息，避免把相近对象的课表混为一个结果。

问题：网络失败后原有课表会消失吗？
解决方法：软件优先保留本机缓存和上一份可用发布数据。网络恢复后可在设置中安全刷新；不要在尚未确认新数据可用时清除全部缓存。

问题：如何停止课程提醒？
解决方法：进入课程提醒列表，选择对应提醒并点按暂停；不再需要时点按删除并在确认提示中确认。若微信通知授权不足，可使用列表中的补充授权入口。

## 十九、术语表

| 术语 | 解释 |
| --- | --- |
| 当前课表 | 首页、今日课程和提醒功能当前采用的一份班级课表或个人课表。 |
| 教学周 | 学校学期内用于安排课程的周次编号，课程是否显示还取决于课程自身的周次范围。 |
| Release Pack | 经过整理、校验并发布的课表索引、课程详情、教学周等只读数据集合。 |
| 个人课表 | 用户通过本人授权读取、文件导入或手动编辑形成并在本机使用的课程安排。 |
| 未排入课程 | 已经读取但缺少可确定的星期、节次或周次，暂时不能放入周课表网格的课程。 |
| 连续空闲 | 教室在所选日期从指定节次起连续没有已发布课程占用的节数。 |
| 小佛助手 | 佛课小表内用于处理课表、教室、地点、提醒等校园任务的交互入口。 |
| 本机缓存 | 保存在当前微信设备上的课表、设置和最近结果，用于提高加载速度和网络异常时继续查看。 |
| 数据版本 | 用于识别当前课表发布批次及其更新时间的版本信息。 |
| 课表贡献 | 用户提交不含账号凭据的班级课程候选数据，由管理员审核后决定是否并入公共课表。 |
