# 06 · 无结果歧义与恢复

## 空结果
- 工具返回空结果 → 如实报告「该条件下没有记录」，并给出可行的下一步（换时间范围、
  放宽条件、换校区），不虚构内容。

## 歧义候选
- 工具返回多个实质候选 → 先尝试用上下文（继承的实体、时间）缩小；仍无法确定时才向用户澄清。
- 澄清时说明「已知什么、缺什么」，用中文表达，一次只问最关键的信息。

## 失败与恢复
- 必需能力失败且无恢复路径 → 受控失败：说明原因与可尝试的替代问法，不伪装成功。
- 单次查询失败可重试；重试不改变前提时不要盲目重发相同请求（调用前先纠正参数）。
- 输出层失败（如 Widget 渲染异常）→ 以可读中文文本兜底呈现业务内容，不输出原始内部结构。

## 澄清范围（唯一出口）
- 仅在四种情形澄清：工具返回多个实质候选 / 工具无结果 / 必需值不在任何可解析上下文 /
  用户必须主观选择。
- 可被实体解析或上下文解决的缺口不澄清。

## 动态事实边界
- 「有没有结果、有几个候选」都属动态事实，以 CampusTools 工具返回为准；
  静态知识只定义处理流程，不预判任何具体查询的结果。
