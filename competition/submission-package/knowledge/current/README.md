# Knowledge Base 2.0（当前 SSOT）

本目录是知识库的**唯一当前 SSOT**。旧 `knowledge/` 根目录下的历史文档已标记
legacy，不再作为当前事实来源（见 `../legacy/LEGACY.md`）。

## 静态知识与动态事实的分工
- 本库只承载**静态知识**：定位、规则、方法、边界、流程。静态知识不含任何运行时数值。
- **动态事实**（课表、空教室、负载、利用率、风险结论、绑定状态、数据版本）一律以
  CampusTools 确定性工具返回与小程序端实际状态为准；本库只描述如何核验、何时重查、如何恢复。
- 静态知识绝不断言：具体教学周、学期日期、实体列表与数量、数据版本号、负载数值。

## 更新纪律
- 不写研发版本号（Rxx / Runtime / 演示版本号），不写测试实体、固定日期与匿名编号。
- 不把测试示例当作生产规则；示例仅为表达能力示意。
- 新增动态事实描述必须先说明其工具来源；禁止在本库沉淀运行时数值。
- 修改本库属于知识库写操作：需人工确认、留审计痕迹、可回滚（版本控制）。
