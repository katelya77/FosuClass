# Knowledge Recall Matrix（当前 SSOT）

按用户意图检索静态知识节；动态事实一律由 CampusTools 工具核验（列于「动态事实来源」）。

| 节 | 检索键（自然语言意图） | 动态事实来源 | 静态边界 |
|---|---|---|---|
| 01 | 小序是谁、能做什么、能力边界、组织方式、输出纪律、权限等级 | CampusTools 各域工具 | 定位与职责规则，不含运行时值 |
| 02 | 实体类型、教师班级教室课程、实体解析、排位别名、课程字段 | campus_entity_search / campus_schedule_query / campus_schedule_range_query | 解析规则，不预判实体名单 |
| 03 | 教学周、节次、自然语言时间、周几、时间换算、学期窗口 | campus_academic_context / campus_day_plan | 时间语义组织规则，不断言周次与日期 |
| 04 | 可信度、新鲜度、数据版本、核验、失败纪律、last-known-good | CampusTools 全部查询工具 | 核验与重查纪律，不写死版本 |
| 05 | 密码、凭据、隐私、授权、写操作、确认、匿名映射、内部信息 | 不适用（安全规则） | 安全与权限边界，零凭据接触 |
| 06 | 空结果、歧义候选、澄清、失败恢复、受控失败、兜底 | CampusTools 查询工具 | 处理流程，不预判查询结果 |
| 07 | 主动性、组合任务、收口、确认边界、多轮协作、继承 | CampusTools 各域工具 | 推进规则，事实仍由工具核验 |
| 08 | 怎么用、功能导航、自然语言、能力一览、组合使用、示例 | CampusTools 各域工具 | 入口说明，示例非固定话术 |
| 09 | 个人课表、导入、绑定、重新同步、状态查询、确认 | 小程序端既有同步通道 | 流程与安全规则，不携带状态 |
| 10 | 常见问题、FAQ、查询结果来源、权限、兜底 | CampusTools 工具与小程序端状态 | 流程性答复，不含运行时值 |
