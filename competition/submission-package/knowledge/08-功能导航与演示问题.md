# 08 功能导航与演示问题

> 本文档用于回答「小序能干什么、怎么问、有哪些示例、演示时评委可能问什么」。稳定知识，动态事实一律走工具。

## 一、适用范围

- 本文档回答「小序能干什么、怎么问、有哪些示例、演示时评委可能问什么」，属于能力导航与演示类稳定知识；动态校园事实一律走工具，本知识库不承载动态查询结果。
- 五类核心能力与示例问法：

| 能力 | 说明 | 示例问法 |
|---|---|---|
| 1. 多维课表查询 | 班级/教师/教室/课程四维课表，支持整周/单日/节次 | 「T03老师第1周整周课表」「2025级A班周三下午有什么课」「A1-101 这周被谁用」 |
| 2. 空教室规划 | 指定日期/星期/节次/校区/容量/连续节次的空闲教室 | 「校区A 2026-09-03 下午有哪些空教室」「找个能坐60人以上的空教室」「B校区第1周周一第5-6节连续2节空教室」 |
| 3. 课程冲突与风险 | 单对象自身冲突/跨校区赶场；显式双对象比较 | 「检查一下他的风险」「T09这一周有没有赶场」「比较T03和T09第1周的风险」 |
| 4. 今日校园计划 | 演示用户某天课程+空档+自习建议 | 「帮我安排2026-09-04的一天」「下一天呢」「明天有课吗」 |
| 5. 校园教学态势 | 未来四周校区/教师负载、空间压力、TopN、全局风险 | 「未来四周哪个校区最忙」「从8月25日看看未来几周校园运行情况」「看Top1课表」「检查Top1风险」 |

## 二、规则

- 功能导航话术（面向评委）：「我可以帮你做五件事：
  ① 查课表——按老师、班级、教室或课程，看某一周或某一天的安排；
  ② 找空教室——按校区、时段、容量、连续节次筛选；
  ③ 查风险——单个老师自己有没有时间冲突或跨校区赶场，也可以显式比较两位老师；
  ④ 安排一天——基于真实课表给你当天的课程和自习空档建议；
  ⑤ 看全局——未来四周哪个校区最忙、老师负载、教室压力，还能从全局钻取到具体课表或风险。
  你可以直接说需求，比如『校区A明天下午有哪些空教室』。」
- 首页顶部 3 个示例问题（应用设置只允许 3 个）：
  1. `T03老师第1周周一有什么课?`
  2. `A校区第1周周一第5-6节有哪些60人以上的空教室?`
  3. `功能示例`
- 每次结果应展示「已核验 + dataVersion=competition-demo-v2」，让评委看到可核验性。

## 三、正确示例

- 演示建议链路（验证跨域手记与状态继承）：
  - 课表 → 检查风险 → 看当天/下一周（验证 self-risk 与 FOLLOW_UP 继承）
  - 空教室 → 换校区/改节次/加容量（验证 slot 覆盖）
  - 态势 → Top1 课表 → Top1 风险（验证钻取与回传）
  - 日计划 → 下一天（验证日期推进）

## 四、错误示例

- ❌ 用本文档回答「T09周三有什么课」（动态事实必须走工具）
- ❌ 把示例问法中的「60人以上空教室」当真实结果背诵
- ❌ 回答「数据是真实的吗」时含糊其辞（必须明确匿名演示数据）

## 五、边界情况

- 动态事实边界（重点）：
  - 课表、空教室、冲突、风险、日计划、校园态势 = **动态校园事实** → 必须走 CampusTools，**禁止知识库直接回答**。
  - 本知识库只提供「问法示例」和「能力说明」，其中的课程/教师/教室名称只是举例，**绝不能作为动态查询结果复用**。
  - 用户一旦问具体课程、教师、教室、空闲、冲突、计划 → 立即转对应工具/域 Agent。
- 支持多轮吗？→ 支持：继承已确认对象，只更新变化条件；新任务自动切换并清除旧上下文。
- 能写数据吗？→ 不能，只读查询助手。
- 能推广到其他学校吗？→ 可以：替换匿名数据 + 重生成 dataVersion 即可复用整套工具与 Agent。

## 六、工具和知识库的职责划分

- 数据是真实的吗？→ 赛事匿名演示数据 v2，3 校区/12 教师/6 班级/24 课程/36 教室；不涉及真实师生。
- 凭什么信你的结果？→ 动态事实全部由确定性工具计算，模型不生成课表；每次带 dataVersion 与核验状态。
- 职责划分：课表、空教室、冲突、风险、日计划、校园态势等动态校园事实由 CampusTools 确定性工具计算并返回 Evidence；知识库只提供「问法示例」「能力说明」「演示注意事项」等稳定知识；知识库内容不得作为动态查询结果，也不得覆盖或改写工具给出的事实。
