# 01-多维课表查询

> 这是 ADP 手工搭建契约，不会自动覆盖平台中已经创建的开始输入。动态事实只来自 CampusTools。

## 1. 触发描述

用户要查询某个班级、教师、教室或课程的课程安排；不处理空教室、两对象冲突或个人今日计划。

## 2. 最小节点（12 个）

```text
1. 开始
2. 参数提取
3. 必填判断
4. 缺参追问
5. 日期解析 → get_academic_context
6. 日期结果判断
7. 课表查询 → query_schedule
8. 结果契约判断
9. 歧义或不存在
10. 工具/核验失败
11. 空结果或课表卡
12. 结束
```

## 3. 业务参数契约

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `entity_type` | string | 是 | class|teacher|room|course |
| `entity_name` | string | 是 | 匿名实体名；工具内部完成最终解析 |
| `date_text` | string | 否 | 缺省时 get_academic_context 按 Asia/Shanghai 今天解析 |
| `week` | number | 否 | 1-20；显式教学周查询可直接传业务工具 |
| `weekday` | number | 否 | 1-7 |
| `period_scope` | object | 否 | {start,end}；上午1-4、下午5-8、晚上9-10 |

必填条件：`entity_type`、`entity_name`。

时间策略：时间不是必填项；合法显式 week 清空重复 date_text 后由 query_schedule 校验；没有合法显式 week 时，date_text 继续交给 get_academic_context 确定性解析。

## 4. 已有 ADP 输入兼容

当前页面已存在：`entity_type`、`entity_name`、`date_text`、`week`、`weekday`、`period_scope`、`campus`。不要自动删除或重建。

- `campus`：保留现有 ADP 输入但不映射；query_schedule 不消费此字段，后续可由用户手工隐藏或删除。

## 5. 参数提取提示词

```text
你是“校园智序 · 小序”的多维课表查询参数提取器。只提取参数，不回答课程事实。

只根据当前用户消息与最近一次已确认且仍属于同一课表查询任务的上下文提取：
- entity_type: class|teacher|room|course
- entity_name: 对象名称
- date_text: 受控自然语言日期
- week: 1-20
- weekday: 1-7
- period_start / period_end: 1-10
- time_scope: day|week

严格规则：
1. 教师1→教师001；教师12→教师012。
2. A班→2025级A班；a1-101→A1-101。
3. 上午=1-4，下午=5-8，晚上=9-10。
4. 没有合法显式 week 时，“本周三/这周三/下周五/明天/后天”等受控自然语言日期写入 date_text，继续交给确定性日期工具解析。
5. 用户明确给出“第N周”“第N周课表”“第N周有哪些课”时，必须输出 week=N、time_scope=week、weekday=null、date_text=null；禁止 date_text="第N周"。
6. 用户明确给出“第N周周X”时，必须输出 week=N、weekday=1-7、time_scope=day、date_text=null；显式 week/weekday 已足够时禁止在 date_text 重复表示同一时间条件。
7. 合同示例“查询教师003第1周的课表”必须得到 entity_type=teacher、entity_name=教师003、week=1、weekday=null、date_text=null、time_scope=week。
8. 合同示例“查询教师003第1周周二的课”必须得到 entity_type=teacher、entity_name=教师003、week=1、weekday=2、date_text=null、time_scope=day。
9. “那周五下午呢”只更新时间并继承最近一次已确认对象；用户明确新对象时覆盖。
10. 不确定的字段留空或 null；绝不虚构课程、教师、教室、校区、周次或节次事实。
11. entity_type 或 entity_name 缺失时不要猜测，留空供下游追问。
```
## 6. 固定匿名常量

- 无。

## 7. 工具映射

| 工作流值 | CampusTools 输入 |
|---|---|
| `entity_type` | `entityType` |
| `entity_name` | `entityName` |

| `weekday` | `weekday` |
| `period_scope.start` | `periodStart` |
| `period_scope.end` | `periodEnd` |

## 8. 分支契约

- get_academic_context success=false 或 inSemester=false → tool_error
- query_schedule error.code=AMBIGUOUS_ENTITY → entity_issue(choice)
- query_schedule error.code=ENTITY_NOT_FOUND → entity_issue(reply)
- success!==true / dataVersion!==APP.data_version / evidence.verified!==true → tool_error
- success=true 且 items=[] → result(empty reply)
- success=true 且 items 非空 → result(schedule widget)

- 任何工具失败、版本不一致或 verified=false 都进入失败回复；生成模型不得补造课程、教室、冲突或计划事实。

11. 张老师的课

## 10. 多轮上下文

只继承最近一次已确认且仍属于同一任务的字段；用户明确新值时覆盖，切换任务时清空无关字段。
