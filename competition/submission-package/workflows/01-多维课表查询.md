# 01-多维课表查询

> 这是 ADP 手工搭建契约，不会自动覆盖平台中已经创建的开始输入。动态事实只来自 CampusTools。

## 1. 触发描述

用户要查询某个班级、教师、教室或课程的课程安排；不处理空教室、两对象冲突或个人今日计划。

## 2. 最小节点（12 个）

```text
1. 开始
2. 参数提取
3. 必填判断
4. 缺参追问
5. 日期解析 → get_academic_context
6. 日期结果判断
7. 课表查询 → query_schedule
8. 结果契约判断
9. 歧义或不存在
10. 工具/核验失败
11. 空结果或课表卡
12. 结束
```

## 3. 业务参数契约

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `entity_type` | string | 是 | class|teacher|room|course |
| `entity_name` | string | 是 | 匿名实体名；工具内部完成最终解析 |
| `date_text` | string | 否 | 缺省时 get_academic_context 按 Asia/Shanghai 今天解析 |
| `week` | number | 否 | 1-20；显式教学周查询可直接传业务工具 |
| `weekday` | number | 否 | 1-7 |
| `period_scope` | object | 否 | {start,end}；上午1-4、下午5-8、晚上9-10 |

必填条件：`entity_type`、`entity_name`。

时间策略：时间不是必填项；date_text/week/weekday 均缺失时调用 get_academic_context({})，再把 resolvedDate 作为今天传给 query_schedule。

## 4. 已有 ADP 输入兼容

当前页面已存在：`entity_type`、`entity_name`、`date_text`、`week`、`weekday`、`period_scope`、`campus`。不要自动删除或重建。

- `campus`：保留现有 ADP 输入但不映射；query_schedule 不消费此字段，后续可由用户手工隐藏或删除。

## 5. 参数提取提示词

```text
只从用户消息和已确认上下文提取 JSON：
{"entity_type":"class|teacher|room|course|","entity_name":"","date_text":"","week":null,"weekday":null,"period_scope":null,"inherited":false}
教师1→教师001，A班→2025级A班；“那周五下午呢”只更新时间并继承已确认对象。不确定字段留空，不生成课程事实。
```
## 6. 固定匿名常量

- 无。

## 7. 工具映射

| 工作流值 | CampusTools 输入 |
|---|---|
| `entity_type` | `entityType` |
| `entity_name` | `entityName` |
| `resolved_date` | `date（date_text 或默认今天时）` |
| `week` | `week（显式 week 时）` |
| `weekday` | `weekday` |
| `period_scope.start` | `periodStart` |
| `period_scope.end` | `periodEnd` |

## 8. 分支契约

- get_academic_context success=false 或 inSemester=false → tool_error
- query_schedule error.code=AMBIGUOUS_ENTITY → entity_issue(choice)
- query_schedule error.code=ENTITY_NOT_FOUND → entity_issue(reply)
- success!==true / dataVersion!==APP.data_version / evidence.verified!==true → tool_error
- success=true 且 items=[] → result(empty reply)
- success=true 且 items 非空 → result(schedule widget)

- 任何工具失败、版本不一致或 verified=false 都进入失败回复；生成模型不得补造课程、教室、冲突或计划事实。

## 9. 调试样例

1. 查询教师001本周三的课程
2. 2025级A班明天有什么课
3. A班周五下午有课吗
4. 教师1第5周周一的课
5. 教室A1-101今天下午被谁用
6. 高等数学A这周什么时候上
7. 查教师002的课表
8. 帮我查下课表
9. 教师099周三的课
10. 教师001第25周的课
11. 张老师的课
12. （上文教师001后）那周五下午呢

## 10. 多轮上下文

只继承最近一次已确认且仍属于同一任务的字段；用户明确新值时覆盖，切换任务时清空无关字段。
