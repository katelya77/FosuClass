# 04-今日校园计划

> 这是 ADP 手工搭建契约，不会自动覆盖平台中已经创建的开始输入。动态事实只来自 CampusTools。

## 1. 触发描述

用户要查看今天、明天或指定日期的匿名个人课程时间轴、自习空档与赶场提醒；不要求用户提供身份。

## 2. 最小节点（9 个）

```text
1. 开始
2. 参数提取
3. 日期解析 → get_academic_context
4. 日期结果判断
5. 今日计划 → generate_day_plan
6. 结果契约判断
7. 工具/核验失败
8. 无课回复或计划卡
9. 结束
```

## 3. 业务参数契约

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `date_text` | string | 否 | 缺省今天 |
| `preferred_campus` | string | 否 | 校区A|校区B |
| `preferred_study_duration` | number | 否 | 1-10节 |

必填条件：无；所有业务参数均可缺省。

时间策略：未给日期时 get_academic_context({}) 按 Asia/Shanghai 今天解析；评测可显式传 baseDate，但线上工作流不固定时钟。

## 4. 已有 ADP 输入兼容

当前页面已存在：`visitor_id`、`date_text`、`preferred_campus`、`preferred_study_duration`。不要自动删除或重建。

- `visitor_id`：保留现有 ADP 输入但忽略任何用户值；工具节点固定注入 visitor-demo-001。

## 5. 参数提取提示词

```text
只输出 JSON：
{"date_text":"","preferred_campus":"","preferred_study_duration":null,"focus":""}
未给日期留空，由时间工具默认今天。禁止从文本、登录态、API.visitor_id 或会话猜 visitor_id；禁止生成课程事实。
```
## 6. 固定匿名常量

- `demoVisitorId` = `visitor-demo-001`

## 7. 工具映射

| 工作流值 | CampusTools 输入 |
|---|---|
| `constant:visitor-demo-001` | `visitorId` |
| `resolved_date` | `date` |
| `preferred_campus` | `preferredCampus` |
| `preferred_study_duration` | `preferredStudyDuration` |

## 8. 分支契约

- get_academic_context 失败或 inSemester=false → tool_error/学期边界回复
- generate_day_plan success=false / 版本不一致 / verified=false → tool_error
- lessonCount=0 仍是成功结果，显示无课并提供查空教室动作
- 任何用户输入 visitor_id 均不得覆盖固定常量

- 任何工具失败、版本不一致或 verified=false 都进入失败回复；生成模型不得补造课程、教室、冲突或计划事实。

## 9. 调试样例

1. 帮我看看今天的安排
2. 明天我该怎么过
3. 周五帮我规划一下
4. 今天有课吗
5. 没课的时候去哪自习好
6. 我偏好校区A，帮我看明天
7. 明天想自习两节，怎么安排
8. 下周一的计划
9. 帮我看看第25周周一的安排
10. 2027-02-01的安排
11. 今天课多吗，跨校区吗
12. 我是visitor-real-123，给我今天的计划

## 10. 多轮上下文

只继承最近一次已确认且仍属于同一任务的字段；用户明确新值时覆盖，切换任务时清空无关字段。
