## 4. 通用控制项

- **Direct Result = OFF（全部 13 工具）**：工具结果必须经 Agent 语义整理后再回复用户。
- **澄清 Widget**：仅 Main 开启 `clarification=ON`（Widget 风格）；子 Agent 一律 OFF，缺参回 Main。
- **模型**：Console Runtime Baseline 冻结 DeepSeek V4 Flash（Prompt 中无 `model=`，改由控制台统一配置；R51-P2）。
- **handoff**：Child → Main 中心化；禁止 Child→Child 直传；新 Turn 一律由 Main 重新接管。

## 5. 参数/输出可见性

- 参数可见性：见 `R50.1-TOOL-MODEL-VISIBILITY.md`（OpenAPI 真源生成）。
- 内部协议字段（rankContext / temporalContext / sourceTool / queryId / dataHash / raw JSON）不得默认展示给用户。

## 6. 回滚路径

1. 工具侧：删除增量插件条目（保留既有 7+2 ops）→ 恢复 R49.4 绑定。
2. Prompt 侧：重新粘贴 R49.4.1 的 4 份 Prompt（历史版本在 `r49-ma/reports/` 与 git 历史）。
3. Runtime：本轮不部署 CloudBase，远程 `/health` 不受影响。
