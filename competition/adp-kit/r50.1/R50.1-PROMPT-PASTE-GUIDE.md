## 2. 粘贴顺序与注意

1. **先确认工具 Cutover 完成**（见 `R50.1-ADP-CONSOLE-CUTOVER.md` §2）：13 个 Agent Tool 已绑定。
2. 依次粘贴 4 份 final.md 全文（从 `# 校园智序 · 小序 Agent Prompt（R50.1）` 标题开始，到文件末尾）。
3. 粘贴后按上表逐项核对高级设置行；**Main 的 clarification=ON（Widget）、子 Agent 全部 OFF**。
4. Main 的「可用工具」只保留 KnowledgeRetrievalAnswer + Agent transfer，**不勾选任何 CampusTools**（P3）。
5. 不要使用控制台「AI 一键优化」重写 Prompt；不要手工增删段落（P8 门禁保证 final.md 可直接粘贴）。
