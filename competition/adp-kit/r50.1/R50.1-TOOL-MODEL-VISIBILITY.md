# R50.1 Tool/Model Visibility 表（新 6 工具）

> 真源：`r49-ma/tools/openapi/campus-agent-tools.r50-existing-plugin-additions.json`（生成器：`r50.1/generate-tool-visibility.js`，幂等）。
> 可见性规则：`必填`=OpenAPI required；`可选`=缺省有确定性默认；`仅 Console`=该参数只允许 Console/评测调试传（用户请求不含，模型不得生成）。
> 与全量 `campus-agent-tools.adp-import.json` 同 server、$ref 自包含、无明文凭据（既有 `test-adp-import-openapi.js` 派生一致性门禁）。

## 工具可见性总览

| Agent Tool | 底层 CampusTools | 绑定 Agent | Direct Result | 说明 |
|---|---|---|---|---|
| `campus_entity_search` | `campus_entity_search` | 课程空间 7 / 校园洞察 3 | OFF | 实体清单/搜索；全部参数可选（空关键词=清单） |
| `campus_academic_context` | `campus_academic_context` | Main 0（辅助决策） | OFF | Temporal Semantic Core；intent/date/dateText 三选一语义；baseDate 仅 Console/评测调试，用户请求不含 |
| `campus_common_free_time_query` | `campus_common_free_time_query` | 课程空间 7 / 校园洞察 3 | OFF | 多实体共同空闲；entities 必填 2..6 |

| `campus_reschedule_feasibility` | `campus_reschedule_feasibility` | 课程空间 7 | OFF | 调课 What-if 模拟；sourceLessonId/target 必填；绝不修改数据 |

## 参数可见性明细

### campus_entity_search（实体清单/搜索）

| 参数 | 类型 | 必填 | 可见性 | 说明 |
|---|---|---|---|---|
| entityType | string | 可选 | 可选 | 实体类型（可选，缩小搜索范围） |
| keyword | string | 可选 | 可选 | 搜索关键词（可选，空则返回清单） |
| campus | string | 可选 | 可选 | 校区A / 校区B（可选，对支持校区字段的实体过滤） |
| college | string | 可选 | 可选 | 学院 id 或名称（可选，对支持学院字段的实体过滤） |
| limit | integer | 可选 | 可选 | 返回上限，默认 20 |

### campus_academic_context（Temporal Semantic Core）

| 参数 | 类型 | 必填 | 可见性 | 说明 |
|---|---|---|---|---|
| intent | object | 可选 | 可选 | 结构化 temporal intent（对象或 JSON 字符串） |
| date | string | 可选 | 可选 | 显式日期 YYYY-MM-DD（优先级最高） |
| dateText | string | 可选 | 可选 | 今天/明天/后天/本周X/这周X/下周X/第N周周X/YYYY-MM-DD |
| baseDate | string | 可选 | 仅 Console | 评测固定基准日期；缺省使用 Asia/Shanghai 当前日期 |

### campus_common_free_time_query（多实体共同空闲）

| 参数 | 类型 | 必填 | 可见性 | 说明 |
|---|---|---|---|---|
| entities | array | 必填 | 必填 | 2..6 个教师/班级实体 |
| week | integer | 可选 | 可选 | 单周查询（与 weekStart/weekEnd 二选一） |
| weekStart | integer | 可选 | 可选 | 周窗口起点 |
| weekEnd | integer | 可选 | 可选 | 周窗口终点（须 >= weekStart） |
| weekday | integer | 可选 | 可选 | 星期 1..7 |
| weekdays | array | 可选 | 可选 | 星期数组（缺省 1..7） |
| periodStart | integer | 可选 | 可选 | 节次范围起点（缺省 1） |
| periodEnd | integer | 可选 | 可选 | 节次范围终点（缺省末节） |
| minConsecutivePeriods | integer | 可选 | 可选 | 最小连续空闲节数，默认 1 |
| limit | integer | 可选 | 可选 | 返回上限，默认 50 |

### campus_room_utilization_query（教室利用率 Ranking）

| 参数 | 类型 | 必填 | 可见性 | 说明 |
|---|---|---|---|---|
| weekStart | integer | 必填 | 必填 | 起始教学周（必填） |
| weekEnd | integer | 必填 | 必填 | 结束教学周（必填，须 >= weekStart） |
| campus | string | 可选 | 可选 | 校区A / 校区B（可选） |
| building | string | 可选 | 可选 | 楼栋名（可选） |
| roomType | string | 可选 | 可选 | 教室类型（可选） |
| groupBy | string | 可选 | 可选 | 聚合粒度，默认 room |
| sort | string | 可选 | 可选 | highest=利用率最高（默认）/ lowest=最低 |
| topN | integer | 可选 | 可选 | 返回前 N 名（可选，默认全部） |

### campus_reschedule_feasibility（调课 What-if 模拟）

| 参数 | 类型 | 必填 | 可见性 | 说明 |
|---|---|---|---|---|

| target | object | 必填 | 必填 | 目标时段/教室 |

| campus | string | 可选 | 可选 | 校区A / 校区B（可选） |
| weekday | integer | 可选 | 可选 | 星期 1..7 |
| weekdays | array | 可选 | 可选 | 星期数组（缺省 1..7） |
| periodStart | integer | 可选 | 可选 | 节次范围起点（缺省 1） |
| periodEnd | integer | 可选 | 可选 | 节次范围终点（缺省末节） |
| minConsecutivePeriods | integer | 可选 | 可选 | 最小连续空闲节数，默认 1 |
