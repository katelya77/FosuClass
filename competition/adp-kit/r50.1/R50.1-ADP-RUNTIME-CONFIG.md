## 4. 事实边界（与 Prompt 共享）

- 校园动态事实唯一来源 = CampusTools 确定性结果；模型不得生成/补全/改写。
- 空结果（EMPTY_RESULT）如实返回「暂无已核验结果」，不虚构；失败（ERROR）不兜底冒充。
- 内部协议字段（rankContext / temporalContext / sourceTool / queryId / dataHash / raw JSON）不默认展示。
- 生成式模型不作为事实源；网络/数据失败保留上一份可用数据（last-known-good）。
