# R50.1 Generic E2E Matrix（能力族 A~L）

> 测试文件：`r49-ma/tests/test-r50-1-e2e-matrix.js`（14 项，当前 **14/14 PASS**）
> 数据：`mock-data/competition-demo-v3.json`（动态发现实体，不硬编码 ID）
> 链路：真实 server 进程 → HTTP POST `/api/campus_*` → `agent-tools.js` façade → CampusTools
> 性质：表驱动 + 参数化 + 语义输出断言（Paraphrase Gate：不绑定字面句式）

## 能力族总览

| 族 | 能力 | 覆盖工具 | 关键断言 |
|---|---|---|---|
| A | 实体清单/搜索 | campus_entity_search | 空关键词清单；exact/prefix/不存在实体/多候选 |
| B | Temporal Semantic Core | campus_academic_context | 绝对日期/相对日期/当前周/下一周/第N周/周窗口/future_weeks 开学前/学期末截断（`items[0].temporalContext`） |
| C | 单周/范围课表 | campus_schedule_query / campus_schedule_range_query | 四类实体、周窗口展开、过滤回显 |
| D | 空教室 | campus_classroom_search | 校区/容量/连续节次；EMPTY_RESULT 空结果不虚构 |
| E | 共同空闲 | campus_common_free_time_query | 2 实体正例、3+ 实体、无共同空闲（weekday=1 + 10 连节 → 空） |
| F | 群体计划 | campus_group_plan | 正常候选、容量过滤（minCapacity=60 全部候选教室 capacity>=60）、无候选（minCapacity=99999） |
| G | 风险 | campus_risk_check | self（`entityType/entityName`，无第二对象）、显式 compare、赶场警告数组 |
| H | 调课模拟 | campus_reschedule_feasibility | What-if 只返回判断（feasible/conflicts），绝不修改数据、无写 action |
| I | 排名 | campus_teacher_load_query / campus_room_utilization_query | TopN 上界、升降序、room/building/campus 聚合、重复调用字节一致、rank position 语义 |
| J | 跨域组合 | 组合调用 | ranking→schedule、ranking→risk、entity→schedule、common-free→group-plan |
| K | Context stale escape | tools/context-model.js | 跨域新任务丢弃比较/实体/排名 pending 状态 |
| L | Context 契约 | tools/context-model.js | taskContext 存在、显式域生效、无隐藏子任务 |
