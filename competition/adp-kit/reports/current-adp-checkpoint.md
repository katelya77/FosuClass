## 2026-08-11 最新故障

尝试生成：

- 02-V7 `SYS.UserQuery/SYS.RewriteQuery/SYS.ChatHistory` 上下文合并版
- 03-V5 `SYS.UserQuery/SYS.RewriteQuery/SYS.ChatHistory` handoff 版

ADP 能导入 ZIP，但打开工作流后出现“引用的节点不存在”。

### 根因（已定位）

V7/V5 在 JSON `Nodes[].NextNodeIDs` 中已经插入“上下文参数合并” CODE 节点，但工作流顶层 `Edge` 字段仍保留旧的直接连线：

- 02 仍是 `参数提取 -> 日期解析`，新“上下文参数合并”节点在画布上漂浮；
- 03 仍是 `冲突参数提取 -> 双方必填判断`，新“上下文参数合并”节点在画布上漂浮。

ADP 只允许节点引用真实上游节点输出，因此下游所有 `REFERENCE_OUTPUT` 被判定为“引用节点不存在”。

### 修复规则

生成包时必须同时验证：

1. `Nodes[].NextNodeIDs`；
2. 顶层 `Edge` JSON 字符串；
3. 每个 `REFERENCE_OUTPUT.Reference.NodeID`；
4. 被引用节点必须在当前消费节点的上游可达路径中；
5. START 到所有业务节点必须可达；
6. ZIP/XLSX 保持原成功基线，能只改 workflow JSON 就不改 Excel。
