## 2. Semantic Window 最终规则

- `windowContext = { rankingWindow, detailWindow, academicWeek }`；`overviewWindow.count` 与 `academicWeek` 严格隔离。
- 「未来四周教师负载最高」→ `rankingWindow=1..4` → `campus_teacher_load_query(weekStart=1, weekEnd=4)`。
- 「看Top1课表」→ `detailWindow=1..4`（继承 rankingWindow）→ `campus_schedule_range_query`，**不得**默认 week=1、**不得**误成 week=4。
- 「只看第一周」→ `detailWindow=1..1` → fresh `campus_schedule_query(week=1)`（fresh-call 铁律）。
- 「看未来第一周课表负载最高的教师课表」→ teacher-load W1..W1 → stable Top1 → schedule W1..W1；严禁知识库回答/模型数课/Main↔Insight 死循环。
- 四周排名后「检查Top1风险」未指定时间 → 当前无 range-risk 工具 → **Main 澄清时间窗口，禁止静默 week=1**。
- 多周范围课表结果 items 带 `academicWeek` 字段；单周 fresh 调用结果无窗口污染。
- 排位：Top1/Top2/Top3 = 有序列表 position 语义；并列不澄清（如「教师009与教师011并列最高。按当前稳定排序，Top1=教师009，Top2=教师011」）。
