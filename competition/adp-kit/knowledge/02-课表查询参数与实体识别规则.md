# 02 课表查询参数与实体识别规则

> 本文档定义小序在执行课表类查询时的参数规范、实体识别与归一化规则，供参数提取与缺参追问时引用。

## 一、适用范围

适用于所有涉及「班级 / 教师 / 教室 / 课程」四类实体的课表查询、空教室查询、冲突比较与今日计划任务。动态查询一律通过 CampusTools 工具完成，本文档只定义参数与实体规则，不提供任何课程事实。

## 二、支持的实体类型（entity_type）

| 类型值 | 含义 | 合法名称示例 |
|---|---|---|
| class | 行政班级 | 2025级A班、2025级B班、2025级C班、2025级D班 |
| teacher | 教师 | 教师001 ~ 教师008 |
| room | 教室 | 两校区共 22 间匿名教室 |
| course | 课程 | 16 门匿名课程 |

赛事环境仅包含以上匿名实体。真实姓名、真实班级编号、真实楼名不在可查询范围内。

## 三、查询参数规范

### query_schedule（课表查询）
| 参数 | 必填 | 说明 |
|---|---|---|
| entity_type | 是 | class / teacher / room / course |
| entity_name | 是 | 归一化后的实体名称 |
| date_text | 否 | 自然语言日期（今天/明天/本周三/2026-09-03） |
| week | 否 | 教学周次，1-20 整数 |
| weekday | 否 | 星期几，1-7 |
| period_scope | 否 | 节次范围，如 1-2、5-6、上午、下午、晚上 |
date_text 与 week+weekday 均可省略；都未给时由 get_academic_context 按 Asia/Shanghai 的「今天」解析。`campus` 不是 query_schedule 的业务参数；ADP 中已存在的旧输入可以暂时保留，但不得映射成一个无效过滤条件。

### find_available_classrooms（空教室）
| 参数 | 必填 | 说明 |
|---|---|---|
| campus | 是 | 校区A / 校区B |
| week+weekday 或 date_text | 是 | 时间定位 |
| start_period / end_period | 是 | 节次范围（1-10） |
| consecutive_periods | 否 | 要求连续空闲节数 |
| building / capacity | 否 | 楼栋 / 容量筛选 |

### compare_schedules（冲突比较）
- first_entity_type / first_entity_name、second_entity_type / second_entity_name（必填，两个比较对象）
- date_range 或 week+weekday（可选，默认全学期重叠分析）
- period_scope（可选）

### generate_day_plan（今日计划）
- visitor_id 不从用户消息、登录态或 API 参数获取；工作流固定注入 `visitor-demo-001`
- date_text（可选，默认今天）
- preferred_campus / preferred_study_duration（可选偏好）

## 四、实体名称归一化规则

工具调用前必须先经 resolve_entity 归一化：
- 口语数字归一：教师1 / 教师一 → 教师001
- 班级简称：A班 / a班 → 2025级A班
- 大小写、全半角、空格不敏感
- 不得把归一化之外的猜测当作实体：如「那位很高的老师」无法映射，应追问

## 五、缺参与歧义处理规则

1. 缺必填参数 → 追问，且一次只问最关键的缺失项。
2. 实体多候选 → 列出候选让用户选择，不得擅自选定。
3. 实体不存在 → 明确告知并给出可查范围。
4. 时间未指定且无法从上下文继承 → 默认今天并显式说明。

## 六、正确示例

- 「查教师001本周三的课」→ entity_type=teacher, entity_name=教师001, week=当前周, weekday=3
- 「A班明天下午有课吗」→ query_schedule 内部解析 A班→2025级A班，period_scope=下午
- 「校区A明天下午连续两节的空教室」→ campus=校区A, consecutive_periods=2, start/end=下午段

## 七、错误示例

- ❌ 把「教师1」直接当最终名称调工具（未归一化）
- ❌ 用户说「张老师」时编造映射到教师001（真实姓氏不在演示数据内）
- ❌ 缺 campus 时擅自假设校区A（空教室查询 campus 必填，应追问）
- ❌ 用「大概周三有课」这类猜测表达（动态事实必须来自工具）

## 八、边界情况

- week 超出 1-20 → 工具返回 OUT_OF_RANGE，提示学期共 20 周。
- date 不在学期内 → inSemester=false，明确说明日期不在本学期。
- period_scope 与 start/end 同时给出且冲突 → 以更具体的 start/end 为准并说明。
- 多轮中「那周五下午呢」→ 继承上文 entity_type/entity_name，仅更新时间条件。

## 九、工具和知识库的职责划分

- 知识库负责解释字段含义、实体类型、参数格式、缺参顺序和歧义确认规则。
- `resolve_entity` 负责对实际输入进行匿名实体归一化与候选解析，模型不得自行建立映射。
- `query_schedule`、`find_available_classrooms`、`compare_schedules` 与 `generate_day_plan` 负责返回动态事实；工作流只做参数编排、分支控制和展示整理。
