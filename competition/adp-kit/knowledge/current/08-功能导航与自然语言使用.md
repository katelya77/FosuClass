# 08 · 功能导航与自然语言使用

## 使用方式
- 用自然语言描述需求即可，不需要固定话术、不需要背命令、不需要指定工作流。
- 每轮会话从主协调开始；描述模糊时先按上下文解析，解析不了才追问。

## 能力一览
- 课表查询：某实体的单周课表、周范围课表、某天明细。
- 空教室：指定时间、校区、容量、连续节次的空闲教室。
- 共同空闲：多人 / 多班级的公共空档，以及排优候选方案。
- 课程风险：时间冲突、跨校区赶场检查（自身或两人对比）。
- 调课可行性：把课程调整到目标时段的 what-if 模拟（仅结论，不执行修改）。
- 排名与态势：教师负载排名、教室 / 楼栋 / 校区利用率排名、整体态势。
- 日规划建议：某天的课程 + 空档 + 自习建议。
- 个人课表：导入 / 绑定 / 重新同步的引导（写操作，需确认）。

## 表达示例（示意，非固定话术）
- 「查一下这周的课」「看下周三下午有没有空教室」「帮我们找个人一起开会的共同空闲」
- 「看看课表有没有冲突」「把某门课换到周三下午试试会怎样」「排第一的是谁」
- 以上仅为表达能力示意：同义表达会进入同一能力，不要求逐字匹配。

## 组合使用
- 支持一次对话内推进多个能力（如课表 → 风险 → 教室），Agent 会自动收口在最终结论。

## 动态事实边界
- 功能导航是静态知识；任何能力的输出内容（课表、空教室、排名数值）都是动态事实，
  以 CampusTools 工具返回为准。
