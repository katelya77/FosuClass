# 03 教学周、日期节次与自然语言时间规则

> 本文档定义赛事演示环境的学期、教学周、节次时刻与自然语言时间的换算规则。周次与日期换算由工具确定性计算，本文档说明规则本身。

## 一、适用范围

适用于所有带时间条件的查询：课表查询、空教室规划、冲突比较、今日计划，以及「第几周」「周几」「下午」等自然语言时间的理解。

## 二、学期与教学周规则（演示数据 competition-demo-v1）

- 学期首日：**2026-03-02（周一）**
- 学期长度：共 **20 个教学周**
- 第 N 周周一 = 学期首日 + (N-1) × 7 天
  - 例：第1周周一 = 2026-03-02；第5周周一 = 2026-03-30
- 一周内工作日为周一~周日（weekday 1~7），周末默认无课但仍可查询
- 超出第 1~20 周的查询 → 工具返回 OUT_OF_RANGE，应提示学期共 20 周
- 日期不在学期内 → 工具返回 inSemester=false，应明确说明

## 三、节次与时刻表（演示环境）

| 节次 | 时间 | 时段 |
|---|---|---|
| 第1节 | 08:00-08:45 | 上午 |
| 第2节 | 08:55-09:40 | 上午 |
| 第3节 | 10:00-10:45 | 上午 |
| 第4节 | 10:55-11:40 | 上午 |
| 第5节 | 14:00-14:45 | 下午 |
| 第6节 | 14:55-15:40 | 下午 |
| 第7节 | 16:00-16:45 | 下午 |
| 第8节 | 16:55-17:40 | 下午 |
| 第9节 | 19:00-19:45 | 晚上 |
| 第10节 | 19:55-20:40 | 晚上 |

时段映射：上午 = 1-4 节；下午 = 5-8 节；晚上 = 9-10 节；全天 = 1-10 节。
「连续两节」= 相邻节次（如 5-6 节），跨时段（4-5 节）不算连续空闲。

## 四、自然语言时间换算

| 用户说法 | 换算结果 |
|---|---|
| 今天 / 明天 / 后天 | 以当前日期为基准 ±0/1/2 天，再换算教学周 |
| 本周X / 这周X | 当前教学周的第 X 天 |
| 下周X | 当前教学周+1 的第 X 天 |
| 第N周周X | week=N, weekday=X |
| 上午 / 下午 / 晚上 | period_scope 对应节次段 |
| 周X第N节 | weekday=X, period=N |

当前日期由系统时间确定；若「今天」不在学期内（如假期），必须说明并建议查询学期内日期。

## 五、正确示例

- 「本周三」当前为第2周 → week=2, weekday=3
- 「第5周周一上午」→ week=5, weekday=1, period_scope=上午(1-4)
- 「明天下午」→ 当前日期+1，period_scope=下午(5-8)

## 六、错误示例

- ❌ 把「下周三」理解为本周三（周次偏移错误）
- ❌ 用户问「第25周」直接编造结果（超出 20 周应提示越界）
- ❌ 把「下午」当成 12:00 开始（演示环境下午从第5节 14:00 开始）
- ❌ 假期中的「今天有课吗」直接查（应先说明今天不在学期内）

## 七、边界情况

- 周次边界：第20周结束后即学期结束，之后日期一律 inSemester=false。
- 跨年/跨月自然语言（「下个月3号」）→ 换算成具体日期后再判断是否在学期内。
- 仅说「周五下午」未指定周次 → 默认本周（当前教学周），并显式说明所采用的周次。
- 多轮继承时时间词更新：「那改成下周呢」→ 保留对象与 weekday，week+1。

## 八、工具和知识库的职责划分

- 知识库负责说明稳定的学期、节次与自然语言时间换算规则，并提供合法输入示例。
- `get_academic_context` 负责把具体日期换算为教学周、星期和学期内状态；动态查询必须使用其核验结果。
- 工作流负责合并用户本轮时间表达与已确认上下文，不得用模型猜测当前教学周或日期边界。
