## 2. 导入增量 JSON（不删除现有插件）

1. 打开 ADP 控制台 → 插件/工具 → 导入。
2. 导入文件：`r49-ma/tools/openapi/campus-agent-tools.r50-existing-plugin-additions.json`。
3. 该文件 = 恰好 6 个新增 operations（entity_search / academic_context / common_free_time_query / room_utilization_query / reschedule_feasibility / group_plan），$ref 全部 self-contained、server 与全量文件一致、无凭据。
4. **不要**重新导入全量 `campus-agent-tools.adp-import.json`（会与既有 7 工具产生 operationId 冲突）；全量文件仅用于对照/重建参考。
5. 导入后核对：工具总数 = 13；既有 7 个工具的 URL、operationId、请求参数、成功响应语义**逐一不变**。

## 3. 新 6 工具单独验证清单

导入后逐个发起最小真实调用（用匿名演示数据）：

| 工具 | 最小输入 | 预期 |
|---|---|---|
| campus_entity_search | `{ "entityType": "teacher", "limit": 5 }` | 教师清单（确定性排序） |
| campus_academic_context | `{ "intent": { "kind": "current" } }` 或相对日期意图 | temporalContext + resolvedWeek |
| campus_common_free_time_query | 2 个实体 + 教学周/日期 | 共同空闲连续节次窗口（确定性排序） |
| campus_room_utilization_query | `{ "weekStart": 1, "weekEnd": 4, "groupBy": "room" }` | RankingResult 列表（position + tie 元数据） |
| campus_reschedule_feasibility | 实体 + 目标星期/节次/时长 | 可行候选（绝不修改数据） |
| campus_group_plan | 2..4 实体 + 周窗口 | ranked 候选（共同空闲 + 教室 + 容量） |

- 失败关闭核对：未知校区 → 受控错误（非模糊匹配）；反向窗口 → 受控错误；缺必填参数 → 受控错误。
- 每个调用返回 evidence（dataVersion=competition-demo-v3、dataHash、verified=true）。

## 8. Prompt 交付边界（哪些暂时不要手工替换）

- R50 Prompt 真源：`r50/agents/shared/*.md` + `r50/agents/<domain>.md`；可粘贴产物：`r50/agents/compiled/*.md`（由 `build-agent-prompts.js` 确定性生成）。
- **暂时不要在控制台手工替换**现有运行中的 Agent Prompt：
  1. 既有 7 工具语义仍为当前线上契约；R50 组合 Prompt 假设 13 工具全部可用，未完成 §2/§3 前替换会引入未验证依赖。
  2. 现有 Prompt 由 R49.4.1 一致性测试锁定（`r49-ma/tests/test-r49-4-1-prompt-consistency.js`），线上替换属「发布」动作，需用户明确指令。
- 后续 **ChatGPT Prompt Convergence Gate**：在控制台外（本仓库）先跑 `build-agent-prompts.js` 编译 + `test-r50-prompt-architecture.js` 全绿，再按 §2→§3→§4→§5→§6 顺序升级，最后才允许逐 Agent 粘贴 compiled Prompt，并保留上一版本回滚（控制台版本快照/历史）。

## 9. 回滚路径

- 工具回滚：删除新增 6 个 operation（或恢复导入前快照）；既有 7 工具不受影响。
- Runtime 回滚：V3 → V2（index.js 保留 v2 分支，重新同步 v2 数据文件）。
- Prompt 回滚：控制台粘贴上一版本 Prompt（本手册 §8 不手工替换，回滚路径天然保留）。
- 数据回滚：`competition-demo-v2` 仍在同步包内（DATA_FILES 含 v1/v2/v3），/health 显示 dataVersion 以实际加载为准。
