# 05-校园教学态势-R1

> 这是 ADP 手工搭建契约，不会自动覆盖平台中已经创建的开始输入。动态事实只来自 CampusTools。

## 1. 触发描述

用户要查看未来几周校园整体教学运行、每日/每周负载、校区空间压力、教师负载或全局风险；不用于单对象课表、具体空教室、单教师风险或个人日计划。

## 2. 最小节点（6 个）

```text
1. 开始
2. 校园教学态势分析 → get_campus_teaching_overview
3. 结果契约判断
4. 校园教学态势卡
5. 核验失败恢复
6. 结束
```

## 3. 业务参数契约

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `window_start` | string | 否 | R1 固定 2026-08-25 |
| `teaching_start` | string | 否 | R1 固定 2026-08-31 |
| `window_end` | string | 否 | R1 固定 2026-09-27 |

必填条件：无；所有业务参数均可缺省。

时间策略：08-25 至 08-30 是 preparation-period，课程数必须为 0；08-31 起按 W1-W4、周一至周五确定性统计。首版拒绝其他窗口，模型不得自行外推。

## 4. 已有 ADP 输入兼容

当前页面已存在：`window_start`、`teaching_start`、`window_end`。不要自动删除或重建。

- 无；当前 ADP 开始输入均继续使用。

## 5. 参数提取提示词

```text
只输出 JSON：
{"window_start":"2026-08-25","teaching_start":"2026-08-31","window_end":"2026-09-27","focus":"overview|resource|teacher|risk"}
所有指标必须来自 get_campus_teaching_overview；不得由模型统计课程、教室、教师或风险。
```
## 6. 固定匿名常量

- `windowStart` = `2026-08-25`
- `teachingStart` = `2026-08-31`
- `windowEnd` = `2026-09-27`

## 7. 工具映射

| 工作流值 | CampusTools 输入 |
|---|---|
| `constant:2026-08-25` | `windowStart` |
| `constant:2026-08-31` | `teachingStart` |
| `constant:2026-09-27` | `windowEnd` |

## 8. 分支契约

- success=true、dataVersion=competition-demo-v1、verified=true → CampusOverview Widget
- preparationPeriod.lessonCount 必须为 0
- success=false / 版本不一致 / verified=false → Error，不由模型补算
- 05 Widget 尚无当前赛事空间真实 ID 时保持 Pilot 未启用

- 任何工具失败、版本不一致或 verified=false 都进入失败回复；生成模型不得补造课程、教室、冲突或计划事实。

## 9. 调试样例

1. 从8月25日开始看看未来几周校园教学运行情况
2. 未来四周校园教学情况怎么样
3. 最近哪一天最忙
4. 哪个校区下午教室最紧张
5. 未来四周教师负载最高的是谁
6. 校园教学风险总体怎么样
7. 四周内哪个教学周最忙
8. 校区A和校区B资源压力如何
9. 未来一个月有多少次课程
10. 开学前准备期有课吗

## 10. 多轮上下文

只继承最近一次已确认且仍属于同一任务的字段；用户明确新值时覆盖，切换任务时清空无关字段。
