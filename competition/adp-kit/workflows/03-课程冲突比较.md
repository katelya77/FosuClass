# 03-课程冲突比较

> 这是 ADP 手工搭建契约，不会自动覆盖平台中已经创建的开始输入。动态事实只来自 CampusTools。

## 1. 触发描述

用户要比较两个班级、教师、教室或课程的时间重叠/赶场风险；不处理单对象课表或空教室。

## 2. 最小节点（12 个）

```text
1. 开始
2. 参数提取
3. 必填判断
4. 缺参追问
5. 日期解析 → get_academic_context
6. 日期结果判断
7. 冲突比较 → compare_schedules
8. 结果契约判断
9. 歧义或不存在
10. 工具/核验失败
11. 冲突结果卡
12. 结束
```

## 3. 业务参数契约

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `first_entity_type` | string | 是 | class|teacher|room|course |
| `first_entity_name` | string | 是 | 第一个匿名实体 |
| `second_entity_type` | string | 是 | class|teacher|room|course |
| `second_entity_name` | string | 是 | 第二个匿名实体 |
| `date_range` | object | 否 | 唯一时间容器：{date_text,week,weekday}；仅第N周表示整周；缺省今天 |
| `period_scope` | object | 否 | {start,end} |

必填条件：`first_entity_type`、`first_entity_name`、`second_entity_type`、`second_entity_name`。

时间策略：开始节点和参数提取都只使用 date_range，不再并列输出顶层 date_text/week/weekday；“第N周”只给 week、不指定 weekday，表示整周，不得默认周一；ADP 内部若以 0 表示未指定 weekday，compare_schedules 入口仅对本工具将其规范化为整周；缺省时间时按今天比较。

```text
只输出 JSON：
{"first_entity_type":"","first_entity_name":"","second_entity_type":"","second_entity_name":"","date_range":{"date_text":"","week":null,"weekday":null},"period_scope":null,"inherited":false}
A班/B班归一化为2025级A班/2025级B班。只给一个对象时第二对象留空；“第N周”只提取 week=N 且 weekday 留空，只有明确周X时才填 1-7；不预判冲突，不单独输出顶层 date_text/week/weekday。
```

## 8. 分支契约

- compare_schedules 内部解析两个实体；ADP 不预先调用 resolve_entity
- AMBIGUOUS_ENTITY/ENTITY_NOT_FOUND → entity_issue
- success=true、verified=true 且 conflictCount=0 仍是成功结果
- summary.selfCompare=true 时使用“<实体> · 课程安排风险检查”，忙碌课次只显示一次，不得使用“A vs A”标题；rushWarnings 只展示工具已经去重的结果
- success=false / 版本不一致 / verified=false → tool_error

- 任何工具失败、版本不一致或 verified=false 都进入失败回复；生成模型不得补造课程、教室、冲突或计划事实。

9. 比较A班和B班
10. （上文A班后）再和D班比一下
