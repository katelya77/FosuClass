# 工作流 02：空教室规划

> 蓝图用途：在 ADP 工作流编辑器中照此搭建。

## 1. 触发描述

用户想找某个时间段可以自习、开会或活动的空闲教室。典型说法：
- 「校区A明天下午有哪些连续两节空闲的教室？」
- 「现在哪里可以自习」
- 「周五晚上校区B有没有空教室」
- 「找个能坐 60 人的空教室」

## 2. 节点结构

```
开始
 → ① 参数提取（大模型节点，输出 JSON）
 → ② 条件判断：campus / 时间 / 节次 是否齐全
     ├─ 缺 campus → ③a 追问校区 → 结束
     ├─ 缺时间 → ③b 追问时间（或默认今天并显式说明）→ 继续
     └─ 齐全 → ④ 时间换算（代码节点）
         → ⑤ 调用 find_available_classrooms（工具节点）
             ├─ 失败 → ⑥a 失败话术 → 结束
             ├─ EMPTY_RESULT → ⑥b 空结果+放宽建议（放宽连续节次/换校区）→ 结束
             └─ 成功 → ⑦ 结果核验
                 → ⑧ Widget classroom 卡 + 结构化文字 → 结束
```

## 3. 参数规范

| 参数 | 必填 | 说明 |
|---|---|---|
| campus | 是 | 校区A / 校区B；缺失必须追问 |
| week+weekday 或 date_text | 是 | 「现在」换算为当前节次 |
| start_period / end_period | 是 | 由「下午」等时段词换算 |
| consecutive_periods | 否 | 「连续两节」→ 2 |
| building | 否 | 楼栋筛选 |
| capacity | 否 | 「能坐60人」→ minCapacity=60 |

## 4. 参数提取提示词

```
你是校园空教室查询参数提取器。只输出 JSON：
{
  "campus": "校区A|校区B 或空",
  "date_text": "原文时间表达或空",
  "week": "教学周或空",
  "weekday": "1-7或空",
  "start_period": "起始节次数字或空",
  "end_period": "结束节次数字或空",
  "consecutive_periods": "连续空闲节数或空",
  "building": "楼栋或空",
  "capacity": "最小容量数字或空",
  "inherited": "true|false"
}
规则：
1. 时段换算：上午=1-4节，下午=5-8节，晚上=9-10节。
2. 「现在/现在哪儿能自习」→ 用当前日期与当前节次到当天结束。
3. 「连续两节」→ consecutive_periods=2。
4. 缺校区不要假设，留空。
5. 多轮继承上文未更新的条件。
6. 只输出 JSON。
```

## 5. 分支话术

- 缺校区：「想查哪个校区的空教室？校区A 还是校区B？」
- 空结果：「{校区}{时间}没有{连续N节}空闲的教室。可以试试：放宽为单节 / 换校区 / 换个时段。」
- 失败：「这次查询没有成功，请稍后再试。」

## 6. 输出与 Widget

Widget cardType=classroom：
- 标题：{校区} {时间} 空教室
- 副标题：数据版本 competition-demo-v1 · 已核验 · 共 N 间
- 列表：教室号 / 楼栋 / 容量 / 空闲节次
- 按钮：「换校区B」「放宽为单节」「看明天」

## 7. 调试样例（12 条）

| # | 输入 | 预期 |
|---|---|---|
| 1 | 校区A明天下午有哪些连续两节空闲的教室 | 校区A 明天 5-8节 consecutive=2 |
| 2 | 现在哪里可以自习 | 当前日期当前节次起，缺校区→追问 |
| 3 | 周五晚上校区B有空教室吗 | 校区B 周五 9-10节 |
| 4 | 校区A第3周周一上午的空教室 | week3 weekday1 1-4节 |
| 5 | 找个能坐60人的空教室 | capacity=60，缺校区时间→追问 |
| 6 | 校区B明天下午连续三节的 | consecutive=3 |
| 7 | （上文校区A周五后）那下周呢 | 继承条件 week+1 |
| 8 | 有空教室吗 | 缺校区+时间→追问校区 |
| 9 | 校区C明天的空教室 | 校区不存在→提示只有校区A/B |
| 10 | 校区A第25周的空教室 | 越界提示 |
| 11 | 校区A明天下午的空教室（实际无结果场景） | 空结果+放宽建议 |
| 12 | 校区A明天全天哪些教室一直空着 | consecutive=10 或全天逐节展示 |
