# 工作流 01：多维课表查询

> 蓝图用途：在 ADP 工作流编辑器中照此搭建。含触发描述、节点结构、参数提示词、分支逻辑与调试样例。

## 1. 触发描述（填工作流触发条件）

用户想查询某个班级、教师、教室或课程在某个时间的课程安排。典型说法：
- 「查询教师001本周三的课程」
- 「2025级A班明天有什么课」
- 「教室 A1-101 今天下午谁在用」
- 「高等数学这周什么时候上」

## 2. 节点结构

```
开始
 → ① 参数提取（大模型节点，输出 JSON）
 → ② 条件判断：entity_type / entity_name 是否齐全
     ├─ 缺失 → ③a 缺参追问（回复节点）→ 结束（等用户补充）
     └─ 齐全 → ③ 实体归一化（工具节点：resolve_entity）
         ├─ ENTITY_NOT_FOUND → ④a 告知可查范围 → 结束
         ├─ AMBIGUOUS_ENTITY → ④b 候选确认（Widget choice 卡）→ 结束
         └─ 命中 → ⑤ 时间换算（代码节点：date_text→week/weekday，默认今天）
             → ⑥ 调用 query_schedule（工具节点）
                 ├─ 失败 → ⑦a 失败话术 → 结束
                 ├─ EMPTY_RESULT → ⑦b 空结果话术+放宽建议 → 结束
                 └─ 成功 → ⑧ 结果核验（检查 dataVersion/success）
                     → ⑨ Widget schedule 卡 + 结构化文字 → 结束
```

## 3. 参数规范

| 参数 | 必填 | 来源 |
|---|---|---|
| entity_type | 是 | 用户消息或上下文 |
| entity_name | 是 | 归一化后填入 |
| week / weekday | 条件必填 | date_text 换算；都缺时默认今天 |
| period_scope | 否 | 上午/下午/晚上/具体节次 |
| campus | 否 | room 查询时可 narrowing |

## 4. 参数提取提示词（粘贴到大模型节点）

```
你是校园任务参数提取器。从用户消息和对话历史中提取课表查询参数，只输出 JSON：
{
  "entity_type": "class|teacher|room|course 之一",
  "entity_name": "归一化后的实体名",
  "date_text": "用户原文中的时间表达，没有则为空",
  "week": "教学周数字或空",
  "weekday": "星期数字1-7或空",
  "period_scope": "上午|下午|晚上|具体节次 或空",
  "campus": "校区A|校区B 或空",
  "inherited": "是否继承了上文实体 true|false"
}
规则：
1. 口语归一化：教师1/教师一→教师001；A班→2025级A班。
2. 多轮继承：「那周五下午呢」继承上文 entity_type/entity_name，仅更新时间，inherited=true。
3. 真实姓氏教师（张老师等）不在演示范围，entity_name 留空并标记 note="real_name"。
4. 不确定的字段留空，绝不编造。
5. 只输出 JSON。
```

## 5. 分支话术

- 缺参追问（一次只问一项）：「想查哪个对象的课表？可以说班级（如2025级A班）、教师（如教师001）、教室或课程名。」
- 实体不存在：「演示数据里没有「{name}」。可以查：2025级A-D班、教师001-008、22间教室、16门课程。」
- 候选确认：Widget choice 卡列出候选（含所属学院/校区）。
- 失败：「这次查询没有成功，请稍后再试一次。」
- 空结果：「{对象}在{时间}没有课程安排。」+ 放宽建议（换日期/看整周）。

## 6. 输出与 Widget

成功时输出 Widget cardType=schedule：
- 标题：{entity_name} {时间描述} 课表
- 副标题：数据版本 competition-demo-v1 · 已核验
- 列表：节次 / 课程 / 教室 / 校区 / 教师
- 按钮：「看明天」「看整周」「查空教室」

## 7. 调试样例（12 条）

| # | 输入 | 预期 |
|---|---|---|
| 1 | 查询教师001本周三的课程 | teacher 周三课表卡 |
| 2 | 2025级A班明天有什么课 | class 明日课表 |
| 3 | A班周五下午有课吗 | 归一化 2025级A班 周五 5-8节 |
| 4 | 教师1第5周周一的课 | 归一化 教师001 week5 weekday1 |
| 5 | 教室A1-101今天下午被谁用 | room 下午占用列表 |
| 6 | 高等数学这周什么时候上 | course 整周排课 |
| 7 | （上文教师001周三后）那周五下午呢 | 继承教师001 周五下午 |
| 8 | 帮我查下课表 | 缺参追问对象 |
| 9 | 教师099周三的课 | 提示可查范围 |
| 10 | 教师001第25周的课 | 提示学期共20周 |
| 11 | 张老师的课 | 提示匿名环境无法查真实姓名 |
| 12 | 教师001今天有课吗（今天不在学期内） | 说明不在学期内 |
