# 工作流 04：今日校园计划

> 蓝图用途：在 ADP 工作流编辑器中照此搭建。

## 1. 触发描述

用户想要基于个人课表的当日行动建议：几点上课、在哪上、空档去哪自习、有没有跨校区奔波。典型说法：
- 「帮我看看今天的安排」
- 「明天我该怎么过」
- 「今天有课吗，没课的时候去哪自习好」
- 「明天上午上完课去哪自习」

## 2. 节点结构

```
开始
 → ① 参数提取（大模型节点）
 → ② 身份定位：visitor_id（演示环境固定 演示用户001，显式说明）
 → ③ 日期换算 + 学期校验（工具节点：get_academic_context）
     ├─ 不在学期内 → ④a 说明 + 建议查学期内日期 → 结束
     └─ 在学期内 → ⑤ 调用 generate_day_plan（工具节点）
         ├─ 失败 → ⑥a 失败话术 → 结束
         ├─ 当天无课 → ⑥b 无课建议（自习/空教室推荐引导）→ 结束
         └─ 成功 → ⑦ 结果核验
             → ⑧ Widget day_plan 卡 + 结构化文字 → 结束
```

## 3. 参数规范

| 参数 | 必填 | 说明 |
|---|---|---|
| visitor_id | 是 | 演示环境固定 演示用户001（visitor-demo-001） |
| date_text | 否 | 默认「今天」 |
| preferred_campus | 否 | 自习偏好校区 |
| preferred_study_duration | 否 | 偏好自习时长（节数） |

## 4. 参数提取提示词

```
你是今日计划参数提取器。只输出 JSON：
{
  "date_text": "今天|明天|具体日期 或空",
  "preferred_campus": "校区A|校区B 或空",
  "preferred_study_duration": "自习时长节数或空",
  "focus": "用户关注点（自习|吃饭|跨校区|空档）或空"
}
规则：
1. 未给日期默认「今天」。
2. visitor_id 不由用户输入，系统固定演示用户001。
3. 「没课时去哪」→ focus=自习。
4. 只输出 JSON。
```

## 5. 分支话术

- 日期不在学期内：「{日期}不在本学期内（2026-03-02 起 20 周），换个学期内的日期试试？」
- 当天无课：「{日期}没有课。想去自习的话，我可以帮你查空教室。」
- 跨校区提醒：当天有跨校区课程时高亮「注意：第X节在校区A，第Y节在校区B，预留通勤时间」。

## 6. 输出与 Widget

Widget cardType=day_plan：
- 标题：{日期} 校园计划（演示用户001）
- 副标题：数据版本 competition-demo-v1 · 已核验
- 时间轴：课程（节次/课程/教室/校区）+ 空档建议（gap/tip）
- 高亮：跨校区提醒、自习建议
- 按钮：「查空教室」「看明天」「看整周课表」

## 7. 调试样例（11 条）

| # | 输入 | 预期 |
