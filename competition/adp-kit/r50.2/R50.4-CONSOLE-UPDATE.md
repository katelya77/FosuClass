# R50.4 Console 更新说明（统一输出 Widget 双布局）

> 本文档说明如何在 ADP 控制台把已有的 `campus-result-unified-v1` 统一 Widget 升级为 R50.4 双布局版本。
> 只改 Widget 资产，不动 4 个 Prompt、不动 13 个工具绑定、不动转移关系。

## 变更范围（本仓库侧，已就绪）

| 资产 | 变更 |
|---|---|
| `widget/native/campus-result-unified-v1/template.txt` | 双分支渲染：`layoutMode === "week-board"`（周视图）与 result-card（原结果卡）；按钮仍走官方 `sys.chat` |
| `schema.json` | 新增 4 个可选字段：`layoutMode`（enum result-card/week-board）、`weekBoardTitle`、`weekBoardSubtitle`、`days`；week-board 分支要求 `weekBoardTitle`/`days` 非空 |
| `default.json` | 旗舰预览改为整周课表 week-board 样例 |
| `samples/` | 12 个样例：`schedule-week` / `schedule-range`（week-board）+ `schedule-day` / 其余 9 变体（result-card） |
| `contract.json` | 升级 `fosuclass-adp-widget-contract/v5`，登记 `layoutModes` / `dayFields` / `blockFields` / `weekBoardFields` |
| `adapter.py` | 透传布局字段；week-board 数据损坏自动回退 result-card；UTF-8 管道读取（Windows 兼容） |
| `r50.2/widget/view-model.js` | 服务端确定性投影（Envelope + raw → WidgetViewModel），布局规则唯一来源（参考文件，不入控制台） |

## 控制台操作（约 5 分钟）

1. **替换 Widget 资产**：在 Agent Output Widget 编辑中，用本包新文件替换
   `template.txt` + `schema.json` + `default.json`（`widget/` 目录同源副本）。
2. **样例核对**：用 `widget/native/campus-result-unified-v1/samples/schedule-week.json`
   与 `risk.json` 分别预览 week-board 与 result-card 两种形态。
3. **不动项**（保持 R50.2B 现状）：
   - 4 个 Prompt：冻结，不重写；
   - 输出模式：三个 child 均为 `Widget → campus-result-unified-v1`；
   - Tool Direct Result：OFF；
   - Main 0 个 CampusTools、Main → Child / Child → Main 转移关系不变；
   - 13 个自定义操作绑定不重新导入。
4. **验证**：整周课表 → 周视图；单日 / 风险 / 空教室 / 态势 / TopN / 调课模拟 / 空 / 错误 → 结果卡；
   整周视图无课程时自动回退结果卡（sections 兜底）。

## 回滚

- Widget 资产回 R50.2B 版本（git 历史 `be76d1a` 前一版 / 本仓库 `widget/native` 旧文件）。
- Prompt / 工具绑定 / 转移关系零变更，无需回滚。

## 纪律

- 卡内动作仅官方 `sys.chat`，payload 只含用户语义 query；禁止把内部标识塞入按钮载荷。
- widgetId 保持 `null` + `FAIL_CLOSED_REAL_TENCENT_EXPORT_ONLY`。
- 本包只做控制台配置切换与验收；不发布应用、不部署云端。
