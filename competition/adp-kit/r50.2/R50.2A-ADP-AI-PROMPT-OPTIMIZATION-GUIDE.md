# R50.2A · ADP AI 一键优化使用纪律（Prompt Optimization Guide）

> 适用范围：Tencent ADP（Tencent Agent Development Platform）Console 中的「AI 优化 / 一键优化 / Prompt 优化」功能。
> 关联：`R50.2A-PRODUCT-E2E-MATRIX.md`（能力族验收）、`docs/superpowers/plans/2026-08-19-r50.2a-interaction-semantics-prompt-hardening.md`。

## 1. 定位：AI 优化是「候选生成器」，不是事实源

- 生成式模型**不能成为课表事实源**（AGENTS.md）。同理，Console 的 AI 优化输出只是**候选文本**，绝不能被当作唯一真源直接粘贴发布。
- **唯一真源 = 仓库内 `competition/adp-kit/r50/agents/`**：shared 策略 + 4 个域 Prompt 源文件，经 `r50/build-agent-prompts.js` 编译为 `agents/compiled/*.compiled.md` 与 `r50.1/prompts/*.final.md`、`r50.2/prompts/*.final.md` 快照。
- Console 内任何手工改动如果不落回仓库源，下一次重新编译即丢失，且无法被自动化门禁审计。

## 2. 一键优化使用流程

1. **复制当前基线**：从 `r50.2/prompts/<role>.final.md` 复制 Prompt 到 Console（Main → Schedule → Risk → Insight，一次一个，保持可归因）。
2. **触发 AI 优化**：将优化输出作为**候选草稿**保存到临时位置（如 `%TEMP%\opencode\` 或仓库外草稿），不直接覆盖 Console Prompt。
3. **差异评审**：对照候选与基线，逐条判断：
   - 是否引入模型 / Provider / 内部 URL / 密钥 / 真实数据（→ 一律拒绝）；
   - 是否破坏 13 工具绑定、Main 纯编排、Child→Main 回传、What-if 边界、week=1 铁律（→ 一律拒绝）；
   - 是否引入案例硬编码或字面句式绑定（→ 一律拒绝）；
   - 语义是否更紧凑 / 更清晰（→ 可选择性合入仓库源，按 R50.2A 语义门禁回归）。
4. **落回仓库**：修改 `r50/agents/` 源文件 → `node build-agent-prompts.js` + `--export-final` → 同步 `r50.2/prompts/*.final.md` 快照 → 通过语义门禁 → 提交（提交信息注明「来自 Console AI 候选，已人工评审」）。
5. **Console 验证**：用仓库快照覆盖 Console 当前 Prompt，按 `R50.2A-PRODUCT-E2E-MATRIX.md` 执行能力族验收；任何平台侧新发现缺陷回到仓库以 RED→GREEN 修复。

## 3. 禁止事项（红线）

- 禁止直接把「优化后」的 Console 文本粘贴回仓库而不经过门禁与 diff；
- 禁止在 Console 中修改 Tool Direct Result、允许模型改写工具返回、开启 Agent Output Widget（R50.2A 期间）；
- 禁止跳过必跑回归（见下）而宣称「已优化」；
- 禁止把 mock / 生成内容描述为生产验证结果。

## 4. 每次「优化合入」后的必跑回归

```text
npm run test:agent-foundation        # r49-ma 全量（含 R50-P1..P10 / R51-P1..P9 / R50.2A 门禁）
npm run test:agent-regression        # mcp 全量 + check + typecheck + check:openapi
npm run test:ai-competition          # golden + compiler --check + 13/14 绑定一致
npm run test:agent-final-convergence # 最终收敛链路
```

单文件快速自检（未改协议/运行模式时）：

```text
node --test tests/test-r50-prompt-architecture.js tests/test-r50-1-prompt-convergence.js tests/test-r50-2-interaction-semantics.js
node build-agent-prompts.js --check   # workdir: competition/adp-kit/r50
```

## 5. 评判口径（与 R50.2A 语义门禁一致）

| 维度 | 通过标准 |
|---|---|
| 目标意图族 | BROWSE_LIST / SEARCH_ENTITY / AVAILABILITY_DISCOVERY / GROUP_PLANNING / RESCHEDULE_SIMULATION 按目标路由，不按字面句式 |
| 澄清边界 | 只澄清必填缺失；可选空缺不澄清、不虚构、不补默认 |
| 调课语义 | What-if only；target.room 可选；绝不声称已执行 |
| 事实纪律 | 可汇总工具返回数值；绝不新增未返回的动态事实 |
| 输出 | 普通对话无 generic 卡堆叠；内部协议字段不默认展示 |
| 平台配置 | Tool Direct Result=OFF；子 Agent clarification=OFF；Main clarification=ON |
