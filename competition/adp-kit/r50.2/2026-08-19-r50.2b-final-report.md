## 5. 关键契约决策

- **不伪造导出**：统一卡未加入 `widget/native/widget-registry.json` 与 `native-widget-import-bundle-manifest.json`（两者语义为「真实 Tencent ADP .widget 导出」登记；加入即造假）。遗留门禁 `audit-widget-contract.js <file.widget>` 与 `test-native-import-preview-contract.js`（期望 6 个 `.widget`）在真实导出前为 **pending-export**，非失败。
- **泄漏面定义**：contract.json `forbiddenFields` 与 adapter.py 运行时 gate token（含 `evidence`）属文档/守卫本身，从全文本扫描中排除；扫描面 = schema / default / template / samples；`sk-` 用带数字约束正则避免误报。
- **adapter 行为锁定**（python 冒烟）：`_has_internal_keys` 扫描键（小写子串）与值标记（queryid= / datahash / dataversion / sourcetool / rankcontext / temporalcontext / nodeid= / varbizid / authorization: / bearer / sk- / internal. / localhost / 127.0.0.1 / /api/）；泄漏输入 → route=fallback。
