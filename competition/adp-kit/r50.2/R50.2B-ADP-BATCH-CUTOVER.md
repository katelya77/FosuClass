# R50.2B ADP 批次切换指南（Batch Cutover）

目标：**单会话**内把 Schedule / Risk / Insight 三个 child Agent 的输出统一切换到
`campus-result-unified-v1` 结果卡，并保持 R50.2A 的全部语义不变量。不发布应用。

## 1. 切换前基线确认

- [ ] `git status` 干净；当前分支 `feat/campusflow-adp-integration`；PR #49 保持 OPEN（不合并）。
- [ ] `r50.2/console-bundle/prompts/*.final.md` 与 `r50.2/prompts/*.final.md` 字节一致。
- [ ] `node r50.2/prompt-candidate-gate.js` 基线门禁 PASS。
- [ ] 13 个自定义插件绑定清单（`r49-ma/tools/schemas/agent-tools.json`）签名未变。

## 2. 控制台单会话操作（按序）

| 步骤 | Agent | 操作 | 目标值 |
|---|---|---|---|
| 1 | Main | 粘贴 Prompt | `console-bundle/prompts/main-orchestrator.final.md` |
| 2 | Main | 输出模式 | `text`；澄清 Widget `ON`；CampusTools 绑定 `无` |
| 3 | Schedule | 粘贴 Prompt | `console-bundle/prompts/schedule-space.final.md` |
| 4 | Schedule | 输出模式 | `Widget → campus-result-unified-v1`；Tool Direct `OFF` |
| 5 | Risk | 粘贴 Prompt | `console-bundle/prompts/risk-planning.final.md` |
| 6 | Risk | 输出模式 | `Widget → campus-result-unified-v1`；Tool Direct `OFF` |
| 7 | Insight | 粘贴 Prompt | `console-bundle/prompts/campus-insight.final.md` |
| 8 | Insight | 输出模式 | `Widget → campus-result-unified-v1`；Tool Direct `OFF` |
| 9 | 全部 | 转移关系 | Main → 三 child；三 child → Main；**无 child→child** |
| 10 | 全部 | 插件绑定 | 13 个绑定保持；签名未变不重新导入/部署 |

Widget 导入资产：`console-bundle/widget/{template.txt,schema.json,default.json}`；
`contract.json` 仅登记（widgetId=null + FAIL_CLOSED_REAL_TENCENT_EXPORT_ONLY）。

## 3. 可选：AI 一键优化批处理

1. 保存 4 份基线（即 `console-bundle/prompts/`）。
2. 4 个 Agent 逐一点击「AI 一键优化」→ 保存候选 `r50.2/prompt-candidates/{main,schedule,risk,insight}.md`。
3. `node r50.2/prompt-candidate-gate.js --candidates` —— 一次报告四份候选的不变量缺失、
   工具归属漂移、静默默认周、child→child 路由、写操作虚构、内部字段暴露、密钥/内部地址泄漏。
4. 门禁通过 → 回写 `r50/agents/<domain>.md` → 重新编译 → 同步快照 → 跑全部门禁。
5. 门禁不通过 → 回控制台修正后重新保存候选，禁止强行跳过。

## 4. 验收

- 按 `R50.2B-CONSOLE-ACCEPTANCE-MATRIX.md` 的 12 个家族逐条执行并截图（PASS/FAIL 栏位）。
- 每条记录：输入 → 期望归属 Agent/工具族 → 期望 Widget variant/text → 禁止行为 → 结果。

## 5. 回滚

```powershell
Copy-Item r50.2/console-bundle/prompts/*.final.md r50.2/prompts/
```

- child 输出模式改回 `text`；停用/删除 unified Widget 导入（旧票证卡资产不动）。
- 工具/插件绑定零变更，无需回滚。

## 6. 发布纪律

- 不发布应用；不伪造 widgetId；不注册 publish/rollback 类高风险操作。
- 卡内动作仅官方 `sys.chat`（payload 仅用户语义 query）；11 项公开字段白名单外零输出；
  内部标识（查询编号/数据哈希/数据版本/来源工具/排名上下文/节点标识/业务标识/凭证/内部地址）零出现。
