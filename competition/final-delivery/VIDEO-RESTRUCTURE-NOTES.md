# 小序-演示视频 · 宏观二次剪辑建议（VIDEO-RESTRUCTURE-NOTES）

> **前提**：现有视频 `小序-演示视频.mp4`（04:44.212 / h264 / 1920×1080）已经是合格提交物，本次只写建议、**不重做视频**。若最终采纳重剪，需按下文第 5 节的替换纪律操作。
> 本文件回答三个问题：现在的视频在叙事上还有哪些可提升点、如果用剪映二次精修该怎么做、哪些"千万别动"。

---

## 1. 现有视频的定位判断

- **优点（应保留）**：真实录屏 + 真实系统响应，与"可现场验证"的诚信主张一致；时长 4 分 44 秒，低于 5 分钟红线。
- **叙事层面可提升点**（对照新叙事主线"谁在用 → 什么问题 → 怎样帮 → 为什么能做到 → 为什么可信 → 验证程度 → 未来"）：
  1. **开场是否先立"人"再立"系统"**——若现在直接进功能演示，建议片头 5–10 秒先出三张"人物卡"（学生 / 教师 / 教学管理者各一句真实问题），让观众带着角色看演示。
  2. **"0 硬冲突 ≠ 来得及"的反转是否被强调**——这是全场最有记忆点的认知反转，若视频里一闪而过，建议加 2 秒停顿 + 字幕高亮"没有冲突，不等于来得及"。
  3. **模拟调课的"三字段结论"**（可行 / 有提醒 / 真实课表未写入）是否给了足够停留——这是可信度证据，建议定格 2–3 秒。
  4. **数字链的"漏斗感"**（3 → 63 → 7 → A1-201）——若现在是一次性出结果，建议在结果卡出现时补一拍数字标注，强化"筛选漏斗"。
  5. **结尾是否回扣"1500+ 真实起点 + 在线体验入口"**——建议片尾 5 秒落"让教学时空，被理解、被安排。"+ 二维码，与 PPT 收束闭环。

## 2. 剪映 SVIP 二次精修清单（AI 只做后期辅助）

| 项 | 建议 | 理由 |
| --- | --- | --- |
| 字幕 | 全片统一口语字幕；关键词（0 / 4 / 20 分钟 / 63 / 7 / A1-201 / 56 课次 / 112 课时 / 1500+）用品牌珊瑚色高亮 | 数字是全部说服力来源，必须一眼可读 |
| 字幕校对 | 先用智能识别字幕，再人工校对课程名、教师编号、教室号与数字 | 专有名词和数字不能交给自动识别直接定稿 |
| 口播清理 | 只删除口癖、明显停顿与重复句，不让 AI 自动重排整片 | 保留真实操作节奏和人的表达 |
| 声音 | 适量开启人声增强、环境降噪与音量均衡；出现对白时让背景音乐自动压低 | 清楚优先于“电影感” |
| 片头 | 3–5 秒标题卡：`校园智序·小序｜让教学时空，被理解、被安排。` | 评委点开视频第一眼定调 |
| 章节卡 | 在大段落切换处加 1 秒极简章节卡（例：`教师案例·多人协同`） | 评委快进时能立刻定位 |
| 节奏 | 结果卡出现的瞬间剪掉冗余等待，保留 1–2 秒"结论定格" | 演示视频最忌"看加载" |
| 标注 | 演示"已核验实录回放"的段落，角标注明"已核验演示回放 · 非实时"，与网站口径一致 | 诚信主张全链路统一 |
| 转场 | 全片只用叠化/黑场，不用花哨转场 | 与 PPT 只用 Fade 的克制风格一致 |
| 配乐 | 轻科技、温暖、有推进感、低存在感；只把自动踩点作为剪辑参考 | 让数字自己说话，不被音乐抢走 |
| 片尾 | 二维码 + `adp.katelya.top` + 匿名访问提示，停留 ≥3 秒 | 二维码在画面上要能被手机扫到 |

## 3. 建议的段落顺序（若做宏观重排）

以新叙事为骨架重排现有素材（不补拍）：

1. **定调**（≤10s）：标题卡 + 1500+ 真实起点一句话。
2. **学生的一天**：一句话查课 → 连续追问 → 找空教室。
3. **教师·协同**：3 → 63 → 7 → A1-201 数字链。
4. **教师·风险与模拟调课**：0 硬冲突 → 4 转场·20 分钟 → 模拟可行/有提醒/未写入（本段是可信度核心，给足停留）。
5. **管理·下钻**：负载第一 56 课次/112 课时 → 课表 → 风险复核。
6. **可信度快剪**：结果卡 + 核验依据 + 保守失败一句话（≤15s）。
7. **收束**（≤10s）：今天 → 未来 + 二维码 + 品牌主张。

> 顺序原则：把"为什么可信"的证据（第 4、6 段）放在观众已经看到真实能力之后，先建立好感再给证据，说服效率最高。

## 4. 千万别动

- 不改变任何真实操作过程与真实响应时间——可信度来自"真实"。
- 不添加未核验的数据字幕（DAU / 满意率 / 准确率等一律禁止）。
- 不把"已核验实录回放"包装成实时请求。
- 不用 AI 自动重剪整片，不用 AI 花字、炫酷转场、自动包装、闪烁特效和密集音效。
- 界面演示段落与最终提交的网站/程序包版本保持同一叙事口径（"教学空间转场风险"表述，数字 0/4/20 不变）。

## 5. 若采纳重剪：替换纪律（强制）

1. 新视频时长必须仍 < 5 分钟。
2. 用新视频替换后，必须重跑交付管线，让 QA 重新计算 SHA-256 并比对；旧校验值不能沿用。
3. 视频文件名与 FINAL-SUBMISSION 内路径不变，QA 的"视频未重新编码"检查项语义为"SHA 与 source 一致"，替换源文件后该检查自然通过。
4. 重跑后 QA 必须 31/31 PASS 才能作为最终提交物。

## 6. 结论

- **最低成本方案（推荐）**：不动视频本体，仅在答辩现场配合 PPT P6/P7 讲清数字链与三字段结论——视频负责"真实"，PPT 负责"叙事"。
- **加分方案**：按第 2 节做剪映精修（字幕高亮 + 章节卡 + 片尾二维码），约 1–2 小时工作量，无内容风险。
- **完整重排方案**：按第 3 节重排段落，仅在确有富余时间时做。
