# 《校园智序·小序》剪映二次剪辑建议

现有作品演示视频时长 04:44.212，低于 5 分钟。本轮不重新编码视频，只提供后期精修逻辑；PPT 负责讲清楚，视频负责证明“真的能跑”。

## 推荐叙事顺序

1. 开场：校园教学不只是查到课表，还要把人、时间和空间真正协调起来。
2. 学生：一句话查课，也能继续问。最快速度展示查课、只看某天、继续找空教室。
3. 教师协同：三个人什么时候都空？结果只突出 63 → 7 → A1-201。
4. 教师调课：能调，不代表没有风险。突出“可行 + 连续授课提醒 + 不修改真实课表”。
5. 教学管理：从全局发现问题，再下钻原因。负载第一 → 课表 → 风险。
6. 技术证明：主协调 → 专业智能体 → CampusTools → 结果卡，控制在十几秒。
7. 落地与结束：1500+ 底层课表服务用户基础、匿名 Web 体验、二维码与“让教学时空，被理解、被安排”。

## 剪映 SVIP 只做这些

- 智能识别字幕后人工校对专有名词和数字。
- 删除口癖、重复句与无效停顿；不要让 AI 自动重剪整片。
- 适量使用人声增强、环境降噪和音量均衡。
- 背景音乐选择轻科技、温暖、有推进感、低存在感；对白出现时自动压低。
- 四个案例开场可使用统一的大字标题模板，其他地方不堆花字。
- 等待过程可以压缩，真实输入、真实结果和关键证据必须保留。

## 禁止

- 不使用 AI 花字、炫酷转场、自动包装、闪烁特效与密集音效。
- 不新增 DAU、满意度、准确率等未核验指标。
- 不把已核验回放伪装成实时请求。
- 不改变 0/4/20、3→63→7→A1-201、56/112、1500+ 等冻结事实。
