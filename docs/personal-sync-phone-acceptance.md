# 个人课表同步真机验收

PHONE_ACCEPTANCE_REQUIRED = YES

自动化测试只覆盖状态机，不能代替 iPhone 微信真机。下面每一项都要在真机上人工确认。

| 编号 | 步骤 | 通过标准 |
| --- | --- | --- |
| A1 | 无保存密码，点击密码框，连续输入 10 个字符 | 第一字符后键盘不自动收起 |
| A2 | 已有保存密码，点击密码框，开始重新输入 | 第一字符后键盘不自动收起 |
| A3 | 已有保存密码，输入 5 个字符，点小眼睛，继续输入 | 已输入内容不丢失 |
| A4 | 明文状态下关闭小眼睛，继续输入 | 已输入内容不丢失 |
| A5 | 快速连续输入 | 键盘保持，内容不丢 |
| A6 | 退格 | 只删除字符，不重建输入框 |
| A7 | 长按粘贴 | 粘贴内容保留，键盘不因粘贴收起 |
| A8 | 切到后台再回来 | 已输入密码仍在 |
| A9 | 点击页面空白 | 可以主动收起键盘 |
| A10 | 点击“同步最新课表” | 允许键盘收起并开始同步 |
| A11 | 点击“清除账号密码” | 只删除本机账号密码，不删除已导入课表 |
| A12 | 输入、切换小眼睛、同步失败、清除账号 | 密码不出现在 vConsole、Page.data 或遥测 |

记录：机型、微信版本、基础库版本、通过/失败、发生步骤。
