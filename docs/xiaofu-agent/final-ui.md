# 小佛助手最终 UI

## 方向

Campus Copilot / 校园行动助手 — 不是通用 AI 套壳，不是卡片堆叠页。

## Header

- 系统导航栏已显示「小佛助手」
- 页内改为紧凑状态栏：头像 + 对话标题（单行省略）+ 最多 2 个状态 Chip + 记忆 Chip
- 不再重复大号「小佛助手」标题
- 「增强模式」与「增强理解已就绪」不叠行

## 消息

- 普通对话：仅正文（助手无大白气泡）
- 事实任务：正文 + 最多一张主卡；Evidence 默认收起
- Run 完成后压缩为「已核验 · …」，点击展开可核验轨迹
- **默认不展示** 👍 👎 / feedback-row；反馈仅长按菜单 → Toast

## 欢迎页

轻量入口：看今天安排 / 找空教室 / 查班级课表 / 规划自习时间

## Sheets

记忆 / 对话 / 任务 / 更多操作统一 Handle、小型 X 关闭、安全区。

更多（settings sheet）：

- 对话记录
- 记忆（完整中文状态，无截断）
- 小佛浮窗 Switch
- 课表摘要 / 小佛能做什么 / 数据与隐私
- 危险区：清空当前对话（二次确认）
