## 1. 功能验收清单

每项记录：结果（PASS/FAIL/N-A）、证据编号（截图/录屏文件名）、runId（若适用）、备注。

### 1.1 会话与多轮

- [ ] A1 首次进入小佛助手：页面正常渲染，无白屏、无控制台未处理异常
- [ ] A2 发送「我今天有什么课？」：出现真实回答与课表卡片；执行状态（进行中→完成）与最终态一致
- [ ] A3 多轮对话（≥5 轮，含指代「那明天呢？」、纠正「我说的是下周」）：上下文正确，无答非所问
- [ ] A4 长会话（≥20 轮）：页面不卡顿、无内存失控、历史消息正常滚动
- [ ] A5 recentTurns 跨会话恢复：退出页面重进，近期对话上下文仍在（按记忆模式预期）

### 1.2 Run 生命周期与恢复

- [ ] B1 执行中切后台再回前台：Run 状态真实恢复，不出现悬挂「处理中」

## 2. 预期 RunEvent 路径（供对照）

正常一次确定性查询（public）应观察到的状态序列（UI 胶囊/进度条呈现，trial/dev 可对照后台 Run Trace）：

```text
run.started →（首事件 ≤500ms 服务端实测，真机为主观体验记录）
stage: context → decision → skill_tool（tool_progress 可展示）→ verification → response → ui
→ runtime.completed（终态卡片落位，状态复位）
```

取消路径：`run.cancelled` 终态，UI 复位，不出现 completed 覆盖 cancelled。
失败路径：`run.failed` + 中文错误卡，不出现悬挂。
