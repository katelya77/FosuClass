# 小佛助手 UI v3（Campus Copilot）

## 顶部

- 主标题固定：**小佛助手**
- 第二行：当前对话标题（单行省略）
- 1～2 个状态 Chip：稳定/增强/本地 + 记忆状态
- 不再出现“已连接 + 离线模式 + 稳定模式 · 已连接”矛盾组合

## 记忆面板

- 横向布局，标题不竖排
- 宽度 100%，描述占剩余宽度，`min-width: 0`
- 三种操作分开：清空本机消息 / 清除服务端会话状态 / 清除全部云端记忆

## 对话列表

- 三层：标题+当前 / 时间+条数+任务 / 本机|会话状态|已同步 Badge
- 操作收入右上角更多菜单

## 实时执行

- `xiaofu-live-run`：用户消息后轻量阶段展示
- 完成后由 `xiaofu-agent-run` 展示可核验 Steps/Evidence
- 发送中按钮变为停止（取消 Run）
