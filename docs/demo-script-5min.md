# 5 分钟演示视频脚本

## 0:00 背景痛点

展示佛课小表当前首页。说明学生日常需要查课、找空教室、看今日安排、导入个人课表，但功能入口分散，且个人课表涉及敏感信息，需要通过本地规则和最小字段处理。

## 0:30 当前课表

打开首页周课表和今日页，展示当前绑定课表、今日课程数量、数据更新时间和免责声明。强调现有课程表、今日提醒和 Release Pack 能力未被破坏。

## 1:15 查询空教室

进入校园服务管家，点击“现在有空教室吗？”或输入“我现在想找 C7 附近能自习两节的空教室”。展示系统调用 `search_empty_rooms` 工具，返回空教室卡片和“可点击查看详情”按钮，再跳转到空教室页核对。

演示路径可直接使用：
- `/pages/ai-assistant/ai-assistant?demo=empty-room`
- `/pages/ai-assistant/ai-assistant?demo=teacher`
- `/pages/ai-assistant/ai-assistant?demo=meeting`
- `/pages/ai-assistant/ai-assistant?demo=diagnosis`

## 2:15 查询老师/课程

输入“帮我查老师课表”或带教师姓名的查询。展示系统使用全校索引工具返回教师/课程卡片，再跳转到全校查询页或课表详情页。说明事实来自 Release Pack 索引，不额外补写。

## 3:10 推荐组会/自习时间

输入“帮我推荐连续 2 节自习时间”。展示系统基于本地课表摘要计算忙闲矩阵，给出候选节次，并联动空教室 action。

## 4:10 XLS 个人课表导入与安全说明

输入“怎么导入个人课表？”展示 guide 卡片。说明系统不接收学号密码，推荐 XLS 导入，只保留课程名、教师、教室、星期、节次、教学周等字段。

可以补充一句：旧账号密码同步接口已下线，演示只展示 XLS-only 链路。

## 4:40 总结创新和推广价值

总结三点：第一，工具优先，事实可追溯；第二，默认 mock/local 无 key 可演示；第三，国产 Provider 脱敏调用和未来境内部署生产模式都以数据最小化为边界。最后展示 README、Provider 配置、Oracle ARM 开发运维说明和合规文档位置。
