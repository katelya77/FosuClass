# 5 分钟演示视频脚本（竞赛竞争力版）

> 目标：让评委在 5 分钟内理解「可信校园 Agent」——事实可查、一句话闭环、正式版无密钥也能跑。  
> 建议分辨率竖屏（小程序）+ 少量旁白字幕。

---

## 时间轴总览

| 时间 | 段落 | 要打出的“卖点” |
|------|------|----------------|
| 0:00–0:40 | 痛点与产品 | 入口多、怕编造课表、要隐私 |
| 0:40–1:40 | 小佛助手查课表直开 | **工具优先 + 一键打开课表** |
| 1:40–2:40 | 全校页学院筛选一致性 | **Agent 与全校同一数据合同** |
| 2:40–3:30 | 空教室 / 今日任务 | 高频校园任务闭环 |
| 3:30–4:20 | 安全与 public 零模型 | **可验收、可合规演示** |
| 4:20–5:00 | 总结与差异化 | 三句话收口 |

---

## 分镜脚本

### 0:00 开场（40s）

**画面**：佛课小表首页课表 → 切到「小佛助手」。

**旁白要点**：

- 学生每天要查课、找空教室、搜老师，功能散在多个页面。
- 更关键：课表事实不能靠 AI “猜”，要来自学校数据。
- 小佛助手：一句话完成任务，事实来自 Release Pack 确定性工具。

**字幕**：工具优先 · 事实可核查 · 校园任务型 Agent

---

### 0:40 场景一：自然语言打开教师课表（60s）★核心竞争力

**操作**：

1. 输入：「查陈芳老师的课表」（或先「查教师课表」再回复「陈芳」）。
2. 展示：检索结果**卡片**（姓名、学院），非纯文字。
3. 点主按钮 **「打开教师课表」**，或点卡片中的教师行 → 进入 `schedule-view`。
4. （可选加分）再搜较短关键词展示多命中列表，**逐行可点开**不同老师。

**旁白要点**：

- 不是只返回一段文字，而是 **可执行 Action + 可点卡片**：直接打开详情课表。
- 详情按 id 从 Release Pack 加载，**不把整表 courses 塞进 URL**。
- 班级 / 教室 / 课程同一套导航合同（可口头说明，不必四类都点）。

**字幕**：Search → 卡片 → 一点打开课表

---

### 1:40 场景二：全校页与助手结果一致（60s）★差异化

**操作**：

1. 打开「全校」→ 教师 Tab。  
2. **不选学院**，搜「陈芳」→ 有结果。  
3. 选 **动物科技学院**，搜「陈芳」→ 命中。  
4. 选 **人文学院**，搜「陈芳」→ 无结果。  
5. （加分）再搜另一位教师关键词（如「白」或已知姓名）→ 仍有结果，说明索引完整而非“只缓存一个人”。

**旁白要点**：

- Agent 与全校页共用 **Teacher Search Contract**：精确姓名优先 + 学院 `collegeCodes` 严格匹配。
- 生成式模型不改写学院归属。

**字幕**：同一查询 · 同一结果模型

---

### 2:40 场景三：空教室或今日安排（50s）

**操作（二选一，选更稳的一条）**：

- A：「现在 C 区有没有空教室 / 连续两节」→ 卡片 → 点进空教室页核对；或  
- B：「今天有什么课」→ 今日卡片。

**旁白要点**：槽位（校区、节次、连续节数）由工具解析，结果可点进行动。

---

### 3:30 场景四：安全与正式版边界（50s）

**操作**：

1. 设置/说明中展示：不收集学号密码进对话框；个人课表走 XLS 导入。  
2. 口述：**public 正式版外部大模型调用为零**，断网/无 Key 仍可演示确定性能力。  
3. （可选，体验版）点麦克风：授权态说明 → 短录音 → 文字进输入框 → **不自动发送**。

**旁白要点**：隐私状态机可诊断；ASR 失败与权限错误分开提示。

**字幕**：public 零外部模型 · 数据最小化

---

### 4:20 收尾（40s）

**画面**：回到助手 + 首页课表并排（或分屏剪辑）。

**三句收口**：

1. **可信**：课表事实只来自 Release Pack / 确定性工具。  
2. **好用**：一句话查询并能直接打开课表、跳转业务页。  
3. **可交付**：完整源码 + 能力清单生成链 + 自动化门禁；体验版可给评委试用。

**片尾字幕**：仓库名 / 小程序名「佛课小表」/ 小佛助手

## 录制清单（拍摄前勾选）

- [ ] 体验版或开发版已登录，课表有数据  
- [ ] 全校教师索引可加载（能搜到多名教师）  
- [ ] 动物科技学院 / 人文学院筛选项存在  
- [ ] 「打开教师课表」按钮可见（唯一命中时）  
- [ ] 录屏关闭无关通知；语速适中，关键处放大 UI  

## 不建议在 5 分钟里展开的内容

- 过长的 Provider 配置过程  
- 后台管理全部菜单  
- 失败重试过程（可剪掉）  
- 与核心无关的闲聊对话  

## 若时间只剩 3 分钟：必保镜头

1. 助手搜老师 → 打开课表  
2. 全校页陈芳三组对照  
3. 一句安全总结（public 零模型 + 不收集密码）
