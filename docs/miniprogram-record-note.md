# 小程序备案材料指南（个人主体）

本文档为您在微信公众平台进行个人主体小程序备案提供材料填报参考，以规避因“看起来像学校/官方教务服务”或“不符合个人备案要求”而被驳回的风险。

---

## 备案基本填报信息

### 1. 小程序名称
* **推荐名称**：`佛课小表`
* **原则**：建议使用温和中性的效率工具名称。

### 2. 小程序简介
* **推荐简介**：
  > 用于查看课程安排、今日课程提醒和作息时间的个人效率工具。

### 3. 备案备注（非常重要）
* **推荐备注内容**：
  > 本小程序为个人开发的课程表查看与时间管理工具，主要提供课程安排展示、今日课程提醒、作息时间查看、课表选择与本地缓存等辅助功能。小程序面向佛山大学同学提供课程安排参考，但不代表学校、学院、教务部门或任何官方机构，不提供官方教务服务、校园事务办理、招生、培训、收费课程或在线教学服务。课表内容由开发者整理维护及用户反馈修正，仅作为学习生活中的时间安排参考，具体课程安排请以任课教师通知及正式通知为准。

### 4. 服务类目建议
* **工具 / 效率**
* **工具 / 日历**
* **工具 / 信息查询**
  > **注意**：不要建议填写“教育 / 教育信息服务”，除非平台要求必须这样填。当前小程序更适合按个人效率工具定位。

---

## 避坑说明与自查清单

1. **界面与内容自查**：
   * 确保小程序中所有用户可见的静态文案绝对不要使用“佛大课表”、“官方教务”、“学校官方”、“校方平台”或“数据来自佛山大学教务系统”等暗示官方的字眼。
   * 允许在说明文案或免责声明里适度使用“面向佛山大学同学的课程安排参考工具”，但必须同时说明非官方、以正式通知为准。
   * 联系邮箱建议仅保留个人学术/加密邮箱（例如 `katelya77@protonmail.com`），切勿出现学校教工邮箱。
2. **美术设计自查**：
   * 小程序图标（Logo）以及内部背景，绝不能包含学校校徽、官方徽标或任何容易让审核员认为是学校官方服务的图标。建议使用“课”作为 fallback 文字。
